# 文案拆解：人格越独立 爱就越单纯

**类型**：长版（约 3 分钟）｜**概念**：内在动机（借弗洛姆的成熟之爱）｜**标题写法**：把开头金句压缩成几个关键词并列

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 开头 | 金句先行 | 两个并列判断 + “不是……而是……”立刻纠偏 |
| 概念 | 引出“内在动机” | “心理学中有一个概念叫……，它指的是……” + 一句话定义 |
| 机制 | 依赖外部确认 → 付出变交换 → 产生怨恨 | 层层递进，每层一个因果 |
| 权威 | 弗洛姆：爱是一种主动的能力 | 两句只调换语序的对比句，制造记忆点 |
| 反例 | 为了证明独立而羞于需要别人 | 指出“仍然被标准控制” |
| 作者视角 | 作者以前把付出当成本，后来改观 | 第三人称自称，拉近距离 |
| 收益 | 意义感、连接感、自我一致感 | 三个名词排比 |
| 收尾 | 回扣开头金句并升华 | 从“匮乏索取”到“丰盈流动”的对比 |

**可学**：开头 3 句完成“观点 + 纠偏”；同一句话调换语序制造对比；结尾回到第一句。
