# 文案拆解：人生很多问题不是用来解决的，而是用来接受的

**类型**：长版（156 秒）｜**概念**：强迫性思维｜**标题写法**：“X 不是用来 A 的，而是用来 B 的”判断句，标题 = 第一句

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 开头 | 判断 + 一句延伸 | “当你不再挣扎的那一刻，它就不再是问题了” |
| 共鸣 | 每个人都反复想过没答案的问题 | “人最难承受的往往不是坏结果，而是悬在那里” |
| 概念 | 强迫性思维 | “在心理学中，这种……可以被称为……” |
| 场景 | 三个反复追问的念头 | 直接写出脑中的问句 |
| 挖深 | 真正想要的不是答案，而是确定感 | “也就是说……并不一定是……而是……” |
| 收尾 | 接受无法改变的，把目光放回今天 | “问题也许还在那里，但你已经可以越过它” |

**可学**：不靠段子和夸张，靠一层层“也就是说”往下挖；落点是人内心真正的需要。
