# 逐秒拆解：跑路是人这一生最重要的技能

**类型**：中版（113 秒，约 560 字，5.0 字/秒）｜**开场标题**：及时止损（大众熟词，不是学术概念）｜**学术概念**：认知解离（63 秒才出现）
**标题写法**：反常识判断句 + 网络口语“跑路”，把负面词说成“最重要的技能”

## 可学

- **概念后置**：前 60 秒全是“你”的处境和作者的故事，概念到中段才出现，像是在给前面的故事命名。
- **三连并列 → 三个物件**：文案每列一个名词，画面就加一个对应物件。
- **作者亲历写身体感受**：不说“我很痛苦”，而说“每天醒来第一反应不是期待而是疲惫”。
- **严肃与幽默反差**：旁白讲道理，气泡里用网络口语说出内心真实想法。
- **对仗收尾**：“有些……有些……”“不是所有……也不是所有……”。
