# 逐秒拆解：不要允许任何人一边使用你一边否定你的价值

**类型**：中版（116 秒，约 560 字）｜**概念**：认知失调（16 秒出现）｜**开场大字**：认知失调｜**标题写法**：祈使句“不要允许……”，标题 = 第一句

## 前 30%（0–35 秒）怎么抓人

| 时间 | 写法 | 画面 |
| --- | --- | --- |
| 0–5s | **祈使句开场**：直接告诉观众“不要允许……”，带冒犯感和立场 | 碎片拼合：提着一篮苹果的男孩和山羊 |
| 5–15s | **扩大范围**：列举三种价值（劳动 / 经济 / 情绪）→ 条件句“只要你……却……甚至……那就停止” | 弹吉他的人；怀表、电话、钞票逐个出现；红字“被珍惜”“被正视”；白气泡里一句很伤人的原话 |
| 16–27s | **概念 + “简单来说”定义** | 概念卡，红色定义**逐字打出**；人物 + 城市照片 |
| 28–35s | **立刻举例**：一个人接受帮助却不承认你的价值，加一句对方的原话 | 两个人物 + 漫画气泡（对方的原话） |

## 全片画面手法

- 列举时**图标逐个叠加**（怀表 = 时间，电话 = 联系，钞票 = 金钱），关键词用红字竖排。
- **对方的伤人原话**做成白色漫画气泡，一句比一句狠，观众代入感强。
- **核心观点整句逐字打出**在画面上方（打字机效果），下面保留人物场景。
- **循环示意图**：付出 → 否定 → 自我怀疑，红色箭头连成圈。
- 结论段铺雪山照片带，结尾手持红花 + 黑底粉色玫瑰片尾。
