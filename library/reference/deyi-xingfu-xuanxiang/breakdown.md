# 逐秒拆解：幸福的人不是拥有最多选项的人……（选择悖论）

**类型**：中版（120 秒，约 600 字）｜**概念**：选择悖论（17 秒出现，带提出者）｜**开场大字**：选择悖论｜**标题写法**：“幸福的人不是……而是……”结论句

## 前 30%（0–37 秒）怎么抓人

| 时间 | 写法 | 画面 |
| --- | --- | --- |
| 0–5s | **悖论式断言**：“毁掉一个人最快的方式，就是给他……” | 碎片拼合：海边女人的背影 |
| 5–16s | **“我们总以为……可现实却是……”** + 数量递进（几十种、上百种）+ 情绪词（焦虑、纠结、什么都不想选） | 红色老爷车 + 人物 → 蓝天照片 + 悬挂的钟 + 大楼；关键词“焦虑”“纠结”逐个出现 |
| 17–26s | **权威 + 概念 + 定义**：心理学家提出…… | 学者肖像抠图 + 概念卡，定义逐字打出 |
| 27–37s | **最小生活场景**：点外卖反复比较，加内心独白（万一另一家更好吃？）→“这就是……最折磨人的地方” | 外卖食物抠图 + 弯腰纠结的人 + 漫画气泡 |

## 全片画面手法

- **概念清单逐条叠加**：预期后悔 / 机会成本 / 过高期待，每条红字标题 + 括号黑字定义，旁边配复古肖像与雕像。
- **寓言完整演出来**：一头驴、两堆干草、头顶乱线思考泡、最后倒下——每句话一个动作。
- 金句整句逐字打出在上方，下面是人群照片或人物。
- 结尾：问句气泡（“选哪一个更好呢？”→“什么对我最重要？”）对比，再到手持红花和片尾玫瑰。
