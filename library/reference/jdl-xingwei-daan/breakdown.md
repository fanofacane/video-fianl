# 文案拆解：行为就是答案，接受就继续，不接受就离开

**类型**：长版（173 秒）｜**概念**：行动化（精神分析，弗洛伊德）｜**标题写法**：三个短句并列的态度句

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 开头 | 祈使 + 结论 | “不要强迫别人说真话，行为就是答案” |
| 共鸣 | 放不下的不是人，是一个解释 | “明明……却仍然……” |
| 概念 | 行动化 | “精神分析中有一个概念叫做……它指的是……” + 弗洛伊德 |
| 例子 | 嘴上渴望亲密，靠近就疏远 | 不批判，解释其矛盾 |
| 克制 | 不是每个失约都叫行动化 | “当然不是……也不能……” |
| 作者观点 | 最消耗人的是证明对方动机 | 第三人称“东陵越来越觉得” |
| 收尾 | 要确认的是相处方式是否还愿意继续 | “不是……而是……”问句收 |

**可学**：主动补一句限定，显得克制可信；作者段是观点，不是故事。
