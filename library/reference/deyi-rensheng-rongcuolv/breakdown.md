# 文案拆解：为什么曾以为天大的事后来却提都懒得提？

**类型**：短版（约 64 秒）｜**概念**：人生容错率｜**标题写法**：“为什么曾经……后来却……”时间对比问句

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 钩子 | 曾经天大的事后来懒得提 | 时间对比问句 |
| 概念 | 社会学概念“人生容错率” | 只点名，不先定义 |
| 场景 | 一场准备很久的考试发挥失常 | 三个“觉得……”排比写出当时的情绪 |
| 转折 | 十年后回头看，早已模糊 | 新工作、新的人、新城市、新故事四连排比 |
| 点破 | 当时以为决定命运，其实只是插曲 | “原来……” |
| 本质 | 困住人的是认定自己失败 | “从来不是……而是……” |
| 定义 | 不是不会犯错，而是错误不足以定义一生 | 结尾才给定义 |
| 收尾 | 命运推了你一下，让你走另一条路 | 温柔的比喻收尾 |

**可学**：定义放在结尾，先用场景让观众代入；大量“新的……”排比制造开阔感。
