# 文案拆解：早上会起雾，所以迷茫是很正常的

**类型**：长版（约 3.6 分钟）｜**概念**：原因论（弗洛伊德）｜**标题写法**：用开头的比喻改写成一句温柔的安慰，不出现概念名

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 开头 | 贯穿全片的比喻 | 把人生换算成 24 小时，童年是一场梦 |
| 常见理解 | 人们习惯归结为“性格就这样” | 先摆大众说法 |
| 概念 | 原因论：现在有一条很长的来路 | 定义 + 一句画面感的话 |
| 权威 | 弗洛伊德：意识只是心理的一部分 | 讲清核心观点 |
| 例子 | 小时候常被否定的人很在意评价 | 一问一答，再往下追问一层 |
| 推广 | 执着其实是在逃避某种感觉；赚钱与匮乏感 | 第二个例子 |
| 概念 2 | 强迫性重复 | “明明知道……却……”两次 |
| 作者视角 | 作者也爱追问为什么 | 转折：只停留在为什么会困在过去 |
| 排比 | 你可以理解……却不必…… | 两句同构 |
| 收尾 | 回扣 24 小时比喻 | 梦会影响醒来，但不替你决定去哪里 |

**可学**：标题不提概念、只给情绪价值；开头比喻在结尾再用一次并给新含义。
