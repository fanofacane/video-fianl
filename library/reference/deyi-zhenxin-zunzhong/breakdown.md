# 文案拆解：你的真心待人为什么总是不被尊重？

**类型**：短版（约 68 秒）｜**概念**：破窗效应（借用来讲自我定义）｜**标题写法**：“你的 + 行为 + 为什么总是 + 坏结果”问句，直接戳痛点

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 钩子 | 越真心越不被尊重 | 反常识问句 |
| 概念 | 破窗效应 + 一句话结论 | 概念后马上给“取决于你如何定义自己” |
| 场景 1 | 聚餐时被夸，下意识自谦 | 写出人物原话，适合做对话气泡 |
| 场景 2 | 犯错时被人顺势贬低 | 与场景 1 形成前后对照 |
| 点破 | 反复自嘲，别人会当成事实 | “你以为……可……” |
| 延伸 | 掏心掏肺讲过去，伤口变成武器 | 一个比喻：递出软肋 |
| 本质 | 成熟的人不用缺点定义自己 | “并不是……而是……” |
| 收尾 | 你怎么介绍自己，世界就怎么认识你 | 一句可截图的金句 |

**可学**：短版只讲一个场景链；人物原话直接入稿，方便画面做气泡。
