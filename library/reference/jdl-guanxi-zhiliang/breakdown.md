# 文案拆解：人其实需要的不是形式，而是关系的质量

**类型**：长版（约 3.4 分钟）｜**概念**：情感回应｜**标题写法**：“不是 X，而是 Y”判断句，就是全片结论

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 开头 | 否定三个常见答案，给出真正需要的 | 连续三个“不是”，再用五个并列短语描述理想关系 |
| 定性 | 稀缺、可遇不可求 | 价值判断 |
| 转折 | 最深的孤独不是没人，而是有人却靠不近 | “并不是……而是……” |
| 场景 | 聊天、同床 | “可以……却……”句式两次 |
| 结论 | 不是形式而是质量；身份只是“壳” | 比喻：壳与壳里的东西 |
| 概念 | 引出“情感回应” | 定义 + 三个生活化例子（难过、分歧、缺点） |
| 展开 | 好关系不是永远快乐，而是…… | 多组“不必……也不必……” |
| 作者视角 | 作者认为真正的奢侈品是…… | 回扣开头“奢侈品” |
| 收尾 | 相遇不难，难的是…… | “……不难，难的是……”两组对仗，结尾一句长金句 |

**可学**：标题即结论；用一个比喻（壳）串起全篇；结尾对仗句。
