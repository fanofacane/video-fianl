# 文案拆解：世界不是一个审判你的考场

**类型**：中版（131 秒，约 666 字，5.1 字/秒）｜**开场标题**：聚光灯效应｜**学术概念**：焦点效应（口播里从没念出概念名，只用“目光像聚光灯”这个比喻）
**标题写法**：用全片的核心比喻对（考场 / 广场）当标题，后面接一句画面感很强的三连
**和我们的关系**：与我们《聚光灯效应》同题，是这一期最直接的对标，好句子可以引用或化用

## 可学（和我们第一稿对比后总结）

- **开场是悖论，不是结论**：把两个相反的词说成一回事（自卑 = 自信），观众会停下来想“为什么”。第一句后面紧跟一句解释。
- **概念就是一个比喻**：全片只有“聚光灯”一个核心意象，开头立起来，中段说“倒影”，结尾“关掉那束聚光灯”回收；不用“心理学里有个概念……简单来说……”的教科书式定义。
- **处境写夸张的心理，不写结果**：不是“一下午抬不起头”，而是“觉得全世界都看出来了”“仿佛别人正在开会研究你”。夸张本身就有幽默感，比单独加气泡自然。
- **实验要具体**：年份、人名、怎么做、两个数字，可信度一下就上来了。
- **“你以为……其实……”连用并反转**：第二个“其实”把镜头转向别人（别人也在盯着自己）。
- **记忆反差用无关小细节收尾**：别人记住的只是“那天天气不错”，轻、具体、有画面。
- **有一层“为什么”**：从现象挖到原因（自我审判 ← 过度期待完美），这一层让视频有哲学深度，也回扣了开场悖论。
- **整片没有作者亲历**：靠“你”的视角和密集的金句撑满 2 分钟。
- **排比后半句带转折**：“可以 A，但别 B”，B 才是真正的建议。
