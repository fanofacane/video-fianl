# 文案拆解：接住迟来的哀伤，人生才算真正开始愈合

**类型**：长版（185 秒）｜**概念**：迟发性哀伤｜**标题写法**：“A，B 才算真正……”

| 段落 | 作用 | 手法 |
| --- | --- | --- |
| 开头 | 引一句流行说法再拆 | “男人多情且长情，女人深情而绝情” → 归结为性别会错过真正原因 |
| 概念 | 迟发性哀伤 | “有一个概念叫做……他描述的是……” |
| 机制 | 解脱 ≠ 走出来；失去 ≠ 意识到失去 | 两组“是两回事” |
| 场景 | 遇到小猫想分享、打开聊天窗口 | 极小的生活瞬间 |
| 作者观点 | 最难过的是理解时已无法参与 | “东陵一直觉得……不是……而是……” |
| 平衡 | 迟来的悲伤不代表爱得更深 | “有些人……之前，有些人……之后” |
| 收尾 | 对可能性的哀悼，也是一种提醒 | “你可以看成……也可以看成……” |

**可学**：场景写得极小极真；结尾给两种看法，不说教。
