# 为什么关系越近，越容易互相伤害？（逐字稿）

```
为什么关系越近，
越容易互相伤害？
心理学里有个概念，
叫刺猬法则。
寒冬里，两只刺猬想靠在一起取暖，
可一靠近，就被对方的刺扎疼了；
离远一点，又冷得发抖。
它们试了很多次，
终于找到一个刚好的距离。
人和人之间，其实也是这样。
你对同事客客气气，
回到家，却对最亲的人没有一点耐心。
妈妈多问一句“吃饭了吗”，
你就皱着眉说：知道了，别管了。
不是你不爱他们，
而是你默认，他们不会走。
我们总以为，亲密就是没有距离，
什么都要分享，什么都要过问。
你以为是在靠近，
其实是把刺，一根根扎进了对方的生活。
所以你会发现，很多关系
不是败给了冷漠，
而是败给了没有分寸的亲近。
真正好的关系，并不是没有刺，
而是彼此都知道，刺长在哪里。
你可以靠近，可以依赖，
可以把后背交给对方，
但也要给彼此，留一点转身的空间。
就像那两只刺猬，
不是因为不爱，才保持距离，
而是因为想一直在一起，
才学会了，不把对方扎疼。
```
