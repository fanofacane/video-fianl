# 很多成长不是一点一点发生的，而是在某一天突然发生的（逐字稿）

```
为什么很多人付出了努力，却迟迟等不来改变呢？
因为很多成长不是一点一点发生的，而是在某一天突然发生的。
只是在那之前，你要先熬过一段毫无变化的日子。
而人最难承受的，往往不是辛苦，
而是付出之后，看不到任何回应。
心理学中有一个概念，叫做高原现象。
它指的是练习到某个阶段，进步会突然停滞，
像走上了一片平坦的高原。
1897年，布赖恩和哈特研究电报员学发电码，
发现他们的速度会长时间停滞不前，
然后在某一天，突然跃升到一个新的水平。
原来高原期并不是没有进步，
而是大脑正在悄悄重组：
从一个字母一个字母地听，变成整个单词地听。
也就是说，你看不到变化，不是因为什么都没发生，
而是变化正发生在你看不见的地方。
可我们太习惯用结果来确认努力，
看不到回报，就开始怀疑方向，怀疑自己，
于是很多人，恰恰停在了快要越过高原的时候。
我一直觉得，高原期最难熬的地方不是累，
而是安静，安静到让你以为，自己被世界忘记了。
当然，不是所有停滞都意味着突破，
有时方向真的错了，需要的是调整，而不是硬撑。
真正重要的，是分清自己在原地打转，还是在积蓄力量。
如果是后者，就不必急着向这段日子要答案。
它也许不会立刻奖励你，
但总有一天，会把你送到一个新的地方。
```
