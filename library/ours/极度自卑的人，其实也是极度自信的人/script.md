# 极度自卑的人，其实也是极度自信的人（逐字稿）

```
极度自卑的人，其实也是极度自信的人。
因为他觉得，所有人都在看着他。
我们总觉得，别人的目光像一束聚光灯，
走到哪，就照到哪。
头发没洗，你觉得全世界都看出来了；
跟人打招呼对方没听见，你举着的手都不知道往哪放；
群里发错一句话，整晚翻来覆去，
仿佛别人正在开会，研究你有多蠢。
心理学管这叫聚光灯效应。
康奈尔大学做过一个实验，
让学生穿着印着明星大头照的T恤，走进教室。
他们猜，至少一半的人会注意到，
可真正注意到的，还不到四分之一。
你以为别人盯着你的缺点，
其实别人也在盯着自己的缺点。
我刚工作时，第一次汇报就翻错了PPT，
之后半个月，开会都不敢抬头。
直到同事说：你那次讲得挺好的啊。
原来我记住的，是自己的狼狈；
别人记住的，也许只是那天天气不错。
那束聚光灯，其实是我们自己打的。
不是别人在审视你，是你在审判自己。
世界不是一个审判你的考场，
它更像一个人来人往的广场。
你可以紧张，但别把紧张当成预言；
你可以出错，但不必一遍遍回放。
所谓成长，就是慢慢关掉那束不存在的聚光灯，
然后发现，大家都忙着过自己的日子，
你也可以放心地，去过你的。
```
