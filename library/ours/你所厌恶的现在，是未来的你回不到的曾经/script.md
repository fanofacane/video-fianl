# 你所厌恶的现在，是未来的你回不到的曾经（逐字稿）

```
你所浪费的今天，是昨天死去的人所奢望的明天。
你所厌恶的现在，是未来的你回不到的曾经。
人这一生最奇怪的，莫过于总是活在自己不愿待在的时间里。
很多时候，我们人坐在这里，心却在别处。
吃饭时想着工作，陪家人时，又在回一条消息。
因为人最难待住的，往往不是某个地方，而是此刻。
心理学中有一个概念，叫做心智游移。
它指的是注意力不由自主地离开眼前的事。
2010年，哈佛的基林斯沃思和吉尔伯特，
随机询问了两千多人，此刻在想什么。
发现人们将近一半的时间，都没在想眼前的事；
而走神的时候，人普遍更不快乐。
也就是说，让我们不快乐的，未必是此刻本身，
而是我们总在离开此刻。
三百多年前，帕斯卡就写过：
我们从不停留在现在，
所以我们从未生活，只是希望生活。
可我们总以为，等以后条件好了，再好好生活。
于是今天被用来等待明天，明天又被用来怀念今天。
我一直觉得，人最容易错过的，不是远方，
而是那些当时觉得平常、后来再也回不去的日子。
当然，活在当下不是不管未来，也不是假装没有过去；
而是在想着明天的时候，记得自己还站在今天。
所以不必急着逃离现在，
它也许并不完美，
但它是你唯一能真正活着的时间。
```
