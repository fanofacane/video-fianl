# 为什么你越真心待人，越得不到对方的尊重呢？（逐字稿）

```
为什么你越真心待人，越得不到对方的尊重呢？
太宰治在《人间失格》里给过答案：
无论对谁太过热情，就增加了不被珍惜的概率。
我们总以为，真心能换来真心，
可现实却是，你给得越多，别人越觉得理所当然。
消息你秒回，对方隔天才回一个“嗯”；
朋友随口说想吃什么，你下班绕路去买；
聚会你订位、张罗、买单，最后连句谢谢都没有。
你开始怀疑，自己是不是在热脸贴冷屁股。
经济学里有个概念，叫边际效用递减。
简单来说，给得越多，每一份就越不值钱。
第一颗糖最甜，第十颗只剩下腻。
你以为对方变冷淡了，其实他只是习惯了；
你以为再多给一点就会被看见，
其实给得越多，你越像空气，
人离不开空气，却从来不会感谢空气。
我大学时，每天给室友带早饭，带了整整一学期。
有一天我起晚了，空着手进门，
她头都没抬：“今天怎么没带啊？”
那一刻我站在门口，脸一下烫了。
原来我的好，早就从礼物变成了义务。
太宰治还写过一句：
倘若没有过度的欢喜，便不会有极度的悲伤。
太过热情的背后，往往藏着一份没说出口的期待：
我对你这么好，你也该这样对我。
期待越满，落空时就越疼。
那些糖看似给了别人，其实是在替自己讨一点甜。
你可以热情，但别一次把整罐糖倒空；
你可以真心，但要给自己留一颗。
所谓珍惜，从来不是给得最多，
而是给得刚刚好，对方才尝得出甜。
```
