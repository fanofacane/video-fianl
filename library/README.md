# 参考库与成品库

```
library/
  reference/            只放用户认可的逐字稿（一期一个 .md：逐字稿 + 仿写对照表 + 基本信息）
  ours/                 我们的成片归档（按发布标题）
```

**写逐字稿之前，必须先读 `reference/` 下全部认可稿**，认可稿是我们自己的标准答案，比任何拆解都重要。

## reference/ 认可的逐字稿

| 文件 | 话题 / 概念 | 日期 |
| --- | --- | --- |
| [你所厌恶的现在，是未来的你回不到的曾经](reference/你所厌恶的现在，是未来的你回不到的曾经.md) | 活在当下 / 心智游移 | 2026-10-27 |

新稿被用户认可（不改或只改个别字）后，照这个格式加一个文件，并在上表加一行。只有用户明确认可的稿子才能放进来。

研究对标视频时，可用 `python3 -m video.library ref <slug> <分享链接>` 下载、转写、截帧，结果只存本地 `output/library/<slug>/`，不入库。
