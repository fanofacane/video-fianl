# 参考库与成品库

```
library/
  reference/            写稿参考：认可稿-<发布标题>.md（用户认可的逐字稿）、对标-<slug>.md（对标视频转写稿）
  ours/                 我们的成片归档（按发布标题）
```

**写逐字稿之前，必须先读 `reference/` 下全部认可稿**，再读与本期相近的对标转写稿。认可稿是我们自己的标准答案，比任何拆解都重要。

新稿被用户认可（不改或只改个别字）后，照这个格式加一个 `认可稿-<发布标题>.md`，并在上表加一行。只有用户明确认可的稿子才能放进来。

### 对标转写稿

用 `python3 -m video.library ref <slug> <分享链接>` 加入：自动下载、转写，**转写稿直接写进 `reference/对标-<slug>.md`**（入库）；视频和截帧只存本地 `output/library/<slug>/`。加入后在下表加一行。
