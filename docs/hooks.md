# 开头怎么写

依据：江东陵、得一的口播（下表是原句摘录）和 `library/reference/` 认可稿。完整写法和段落骨架见 [script-style.md](script-style.md)，本文只讲开头 2 句和前 30%。

> 旧版本文列了“六步链”和“6 种开场句式”（反常识断言、悖论、比喻换算……），并要求处境三连写夸张心理、带内心独白。照着写出来像段子，已作废。

## 一、开头 2 句：一句提出，一句接住

对标的开头都是两句一组：第 1 句抛出问题或判断，第 2 句马上回答或延伸。

| 句式 | 对标原句 | 我们用过的 |
| --- | --- | --- |
| 问句：为什么很多人……，却……呢？ | 为什么你越真心待人，越得不到对方的尊重？（得一）<br>为什么曾经以为会毁掉人生的事，后来却连提都懒得提？（得一） | 为什么很多人付出了努力，却迟迟等不来改变呢？→ 因为很多成长不是一点一点发生的，而是在某一天突然发生的。 |
| 判断句：X 不是用来 A 的，而是用来 B 的 | 人生很多问题不是用来解决的，而是用来接受的。→ 当你不再挣扎的那一刻，它就不再是问题了。（江东陵） | |
| 先引一句流行说法，再拆 | 男人多情且长情，女人深情而绝情。→ 这句话常被用来解释……但归结为性别，可能错过了真正的原因。（江东陵） | 太宰治：无论对谁太过热情，就增加了不被珍惜的概率 |
| 祈使句：不要…… | 不要强迫别人说真话，行为就是答案。（江东陵）<br>不要允许任何人一边使用你，一边否定你。（得一） | |
| 条件对称：如果你不……，就要被迫…… | 如果你不花时间去创造你想要的生活，就要被迫花更多的时间去应付你所不想要的生活。（江东陵） | |
| 比喻换算 | 如果把人生换算成二十四小时，二十多岁就是人生的七点半。（江东陵） | |
| 两个日常类比引出概念 | 你学会了骑自行车，就很难回到不会骑的状态；你被蜜蜂蛰过一次，就不会再轻易伸手去碰它。（得一·知识诅咒） | |

要求：
- 用词平实，像在说话；不追求金句感和冒犯感。
- 第 1 句会成为封面字幕；发布标题用陈述句（第 1 句是问句时，用第 2 句或结论句）。

## 二、前 30% 的顺序

1. 开头 2 句（碎片开场里念）。
2. **共鸣**：我们几乎每个人都经历过的处境，落到“人最难承受的往往不是……而是……”。
3. **概念**（约 15%–25% 处）：“心理学中有一个概念，叫做 X。它指的是……”，必要时补“简单来说”。
4. 紧接一个**真实依据**：研究（年份 + 人名 + 做法 + 结果）或一两个安静的生活瞬间。

- [ ] 概念出现前没有绕太久（≤ 25%）
