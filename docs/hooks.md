# 开头与前 30% 怎么写（10 个对标视频总结）

前 30% 决定观众划不划走。10 个对标视频的前 30% 几乎都按同一条“六步链”展开，只是每步的长短不同。
下面总结写法规律并给出示例；写稿时可以直接引用、化用对标视频里合适的句子。

## 一、六步链（按出现顺序）

| 步骤 | 作用 | 常见写法 | 10 个视频里出现次数 |
| --- | --- | --- | --- |
| ① 开场一句 | 让人停下来 | 反常识断言 / 祈使句 / 悖论 / 条件后果 / 比喻 / 问句 | 10/10 |
| ② 拆穿常识 | 制造“原来不是这样” | “我们总以为……可现实却是……”“很多人以为……其实……” | 7/10 |
| ③ 扩大范围 | 让每个人觉得在说自己 | 列举三种：“不论是……还是……”“一段关系、一份工作、甚至一种生活” | 6/10 |
| ④ 情绪落点 | 戳到感受 | 一串情绪词：焦虑、纠结、天塌了、什么都不想选 | 6/10 |
| ⑤ 概念 + 一句话定义 | 给痛点一个名字 | “心理学里有个概念叫……简单来说……”；可带提出者；**也可以用一个比喻直接当概念**（“别人的目光像聚光灯”），比教科书式定义更好 | 10/10，多在 10%–25% |
| ⑥ 最小生活场景 | 立刻落地 | 点外卖、聚餐被夸、考试失常、对方的一句原话；带内心独白直接引语 | 8/10 |

收束一句：“这就是 X 最折磨人的地方”，把场景扣回概念，进入正文。

**概念位置修正**：大多数视频的概念在 10%–25% 处（开场一句 + 一次拆穿之后），只有个别（跑路）放到中段。默认按 10%–25%。

## 二、开场一句的 6 种写法

| 写法 | 结构 | 示例 |
| --- | --- | --- |
| 反常识断言 | X 是 / 才是 Y（Y 与常识相反） | 最在意你出丑的人，其实只有你自己。 |
| 祈使句 | 不要允许 / 别再…… | 别再用别人的脸色，给自己的情绪定价。 |
| 悖论 | X，其实就是 Y（X 与 Y 看似矛盾） | 极度自卑者，其实就是极度自信者。 |
| 条件后果 | 如果你不……就要被迫…… | 如果你不学会拒绝，就要一直替别人的选择买单。 |
| 比喻换算 | 如果把 A 换算成 B…… | 如果把一段关系比作一间屋子，争吵只是开窗通风。 |
| 问句 | 为什么你越……越…… | 为什么你越懂事，越没人心疼？ |

选择标准：能单独成立、能当封面字幕和发布标题、带一点冒犯或反差。

## 三、让人想继续看的 6 个触发点

1. **冒犯感 / 立场**：祈使句和“毁掉一个人”这类说法，先表明态度。
2. **拆穿“你以为”**：观众会想知道“那真相是什么”。
3. **数量递进**：“几十种、甚至上百种”“明明……甚至还……”，把感受推到极致。
4. **直接引语**：对方的一句伤人原话、自己的一句内心独白，比任何形容都有画面。
5. **“你”贯穿**：前 30% 几乎每句都在说“你”。
6. **具体到小事**：外卖、聚餐、考试，越小越真实。

## 四、前 30% 的画面配合

- **0–5 秒**：碎片开场，大字是概念词，照片与情绪相关但不必直白。
- **列举时**：图标 / 物件逐个叠加（时间 = 怀表、联系 = 电话、金钱 = 钞票），关键词红字竖排。
- **情绪词**：彩色关键词逐个弹出（焦虑、纠结）。
- **概念卡**：黑色引号概念词 + 红色定义**逐字打出**；有提出者时配学者肖像抠图。
- **生活场景**：人物抠图 + 漫画气泡（直接引语），一屏 2–3 个元素。

## 五、前 30% 示例（90 秒版的前约 27 秒，约 125 字）

话题：讨好型人格｜开场大字：讨好型人格

> 你对所有人都好，唯独对自己最狠。
> 我们总以为，懂事的人更容易被喜欢，
> 可现实却是，你越懂事，别人越觉得理所当然。
> 加班替同事收尾，聚会抢着买单，
> 明明很累，还要回一句：没事，我可以。
> 心理学里有个概念，叫讨好型人格，
> 简单来说，就是用满足别人，来换取自己的安全感。
> 比如朋友临时放你鸽子，你嘴上说着没关系，
> 回家却一遍遍想：是不是我哪里做得不够好？
> 这就是讨好最累人的地方。

## 六、自查

- [ ] 前 10 秒内有一次“你以为……其实……”的拆穿
- [ ] 有一组三项列举或数量递进
- [ ] 概念（定义或核心比喻）在 10%–25% 处
- [ ] 处境三连写的是**夸张的心理**（“觉得全世界都看见了”），不是平淡的结果
- [ ] 概念后马上接一个最小生活场景，带一句直接引语
- [ ] 前 30% 每句都和“你”有关
