# 开头怎么写

开头没有固定句式。下面是对标视频和认可稿里**真实出现过的开头**，用来感受“好开头是什么样”，按本期内容自己写；也可以参考 `library/reference/对标-*.md` 里相近的对标转写稿。

## 一、开头举例

| 写法 | 原句 | 来源 |
| --- | --- | --- |
| 抛一个问题 | 为什么你越真心待人，越得不到对方的尊重？ | 得一 |
| | 为什么曾经以为会毁掉人生的事，后来却连提都懒得提？ | 得一 |
| 一句判断，再接一句 | 人生很多问题不是用来解决的，而是用来接受的。当你不再挣扎的那一刻，它就不再是问题了。 | 江东陵 |
| 引一句流行说法再拆 | 男人多情且长情，女人深情而绝情。这句话常被用来解释……但归结为性别，可能错过了真正的原因。 | 江东陵 |
| 一句态度 | 不要强迫别人说真话，行为就是答案。 | 江东陵 |
| 对称的条件句 | 如果你不花时间去创造你想要的生活，就要被迫花更多的时间去应付你所不想要的生活。 | 江东陵 |
| 比喻换算 | 如果把人生换算成二十四小时，二十多岁就是人生的七点半。 | 江东陵 |
| 日常类比 | 你学会了骑自行车，就很难回到不会骑的状态；你被蜜蜂蛰过一次，就不会再轻易伸手去碰它。 | 得一 |
| 对仗的名言式 | 你所浪费的今天，是昨天死去的人所奢望的明天。你所厌恶的现在，是未来的你回不到的曾经。 | 认可稿·活在当下（用户给的原话） |

## 二、好开头的共同点

- 用词平实，像在说话，不刻意追求金句感和冒犯感。
- 让人想听下去：留一个疑问，或说出一句观众心里有、但没说出口的话。
- 后面要接得住：问句之后给出方向，判断之后有延伸，不要开头说完就断了。

## 三、其他约定

- 第 1 句会成为封面字幕；发布标题用陈述句（用户偏好），第 1 句是问句时，用回答句或结论句做标题。
- 用户给了现成的句子或名言，优先用用户的。
