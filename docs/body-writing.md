# 正文怎么写、怎么配画面（深度总结）

依据：江东陵、得一对标视频的逐秒画面分析（研究时下载到本地 `output/library/`，不入库）；开头见 [hooks.md](hooks.md)。
话题决定点开率，**正文决定看完率和转发**。以下是正文层面的规律。

## 一、文案

文案写法以 [script-style.md](script-style.md) 第 0–4 节为准（文笔、段落骨架、仿写对照表）。本文原来的“8 个特征”（三连、夸张心理、幽默气泡、编亲历、核心比喻贯穿等）已作废，只保留画面部分。

## 二、画面：文字和素材怎么配

**先看这条（高原现象一期，对照江东陵三期前 30 秒逐秒帧）**：对标每帧元素并不多（2–6 个），画面却满，原因是：
1. **素材大、贴边、出画**：人物占满画面高度（h≈600–700），贴着底边甚至被画框裁掉，字幕直接压在人身上；场景抠图、冰山这类大物件也贴边。不要把人缩到半高悬在纸中间。
2. **一个场景停 12–24 秒，逐句叠加**：同一场景里椅子 → 女人 → 男人 → 气泡 → 挂历 → 桌子一句一句加上去，到后面一屏 4–6 个元素；不要每 4–6 秒就清屏换场。
3. **照片 + 抠图叠层**：全屏照片做底（极光、教室），上面压一个大人物或雕像抠图。
4. **文字少而大**：关键词 56–96 号，分列在物件两侧（确定 ◯ 控制）或人物之间；概念卡是唯一有意留白的画面。
5. 审图用 `scripts/perline_shots.py` 出逐句截图，而不是只看场景结尾帧。

**再看这条（得一·生命的长度、知识诅咒 前 60 秒）**：画面饱满靠**场景层**。
1. **每个场景先铺一块大场景层**，占画面 40%–60%：从角落斜切进来的地球、下半屏的海平线、一条公路风景、整块黑板。用 `strip`、`photo` 或超大的 `image`（可 `rotate` 斜放、出画）。人物和物件压在场景层上。
2. **物件放大到被画框裁掉**：只露一半的钟面、贴右边的耳朵、角落里的头像。
3. **超现实组合**：粉色的手捧着蓝色眼睛、耳朵 + 声波线、金色画框里套一幅人像——一个元素就能讲一句话。
4. **人名、年份用红色竖排**（伊丽莎白 | 牛顿）；概念卡下面也垫一条风景带，不是纯白。
5. **退场向下移动并淡出**（引擎默认 `exit: down`），场景之间不是生硬地消失。


- **逐字打出**：概念定义和核心金句用打字机效果整句逐字出现在画面上方，下面保留人物场景。
- **循环图 / 概念清单**：讲机制时画“付出 → 否定 → 自我怀疑”的红箭头循环；讲多个原因时逐条叠加“红字标题 + 括号定义”。
- **寓言完整演出来**：每句话一个动作（驴、两堆干草、思考乱线、倒下）。
- **分层叠加提升质感（约三分之一到一半的场景用）**：底层放一块沿轮廓抠出的**场景抠图**（建筑、山体、桥、舞台、大树），加一圈白色剪纸边，尺寸大、可以贴边或出框；上层叠人物或物件，压在场景一角，前后关系清楚。前后两句共用一个主体时，可以只换背景层。不是每个场景都要这样，单个抠图、文字卡、全屏照片照常穿插。
- **一个名词一个物件**：文案列举几个名词，画面就逐个叠加几个对应物件（关系 → 夫妻，工作 → 老电脑，生活 → 城市天际线）。
- **新元素节奏**：约每条字幕加一个新元素，一个场景停 10–20 秒逐句叠满，之后整体向下淡出换场。
- **画面饱满度**：场景层 + 2–5 个大元素，画面基本没有大块空白；只有概念卡的上半部是文字留白。
- **底部照片带**用在转折和金句处（城市、公路、山、泳池），给画面一个“地面”。
- **气泡只放人物原话或一句心里话**（“不在乎”“未来的路该怎么走…”“你们是我带过最差的一届”），平实，不刻意搞笑。
- **列举用竖排彩色关键词**（每个词一种颜色），概念卡用“黑色引号概念词 + 红色两行定义”，停留 5–10 秒。
- **同一个人物贯穿一个场景**：场景里换物件、加文字，不换人。
- **素材风格**：复古人物抠图（上世纪中期）、古典雕像、老物件、图标（胶片、握笔手、思考云）、风景照片带混用；超现实组合（涂掉眼睛的肖像、眼球、戴墨镜的孩子）制造记忆点。
- **片尾**：对标账号用固定的片尾标记做账号识别。那是对方的标识，我们不照搬；我们自己的片尾标记待定。

## 三、历史

刺猬法则、聚光灯效应两期的“差距表”是按旧的技巧清单对照的（三连、气泡、亲历），已删除；画面方面的结论都并入了上面第二节。

## 四、出截图前的画面检查清单

- [ ] 每个场景先有一块大场景层（照片带 / 全屏照片 / 超大场景抠图，可斜放出画）
- [ ] 人物和主物件够大：人物接近满屏高度并贴底出画，物件敢被画框裁掉
- [ ] 一个场景停 10–20 秒，元素逐句叠加，最后一屏 3–5 个元素
- [ ] 至少一处超现实组合（一个元素讲一句话）
- [ ] 文字少而大；人名、年份可竖排红字；概念卡下面垫风景带
- [ ] 素材全期不重复；主题意象只在关键处出现
- [ ] 用 `scripts/perline_shots.py` 出逐句截图自查，再给用户
