# 正文怎么写、怎么配画面（深度总结）

依据：参考库 10 个对标视频，重点是四个中版（113–136 秒）的逐秒拆解；开头与前 30% 另见 [hooks.md](hooks.md)；对照我们的第一期《为什么关系越近，越容易互相伤害？》。
话题决定点开率，**正文决定看完率和转发**。以下是正文层面的规律。

## 一、文案：好正文的 8 个特征

1. **开场一句先抓人**：以反常识断言为主（也可用祈使句、悖论、条件后果、比喻、问句，见 hooks.md），三句话内完成“观点 → 拆穿常识 → 代价”。
2. **概念位置**：10 个对标里大多数在 10%–25% 处出现（开场一句 + 一次拆穿之后），只有个别放到中段。默认 10%–25%，详见 [hooks.md](hooks.md)。
3. **“三连”制造共鸣**：同构句连续三次（“越……越……”“像是在否定……”“关系、工作、生活”），每一条都是观众经历过的具体事。
4. **画像一类人**：“能……却……”“知道……却没有……”，观众会自动对号入座。
5. **作者亲历约占 10%–20%，短而有转折**：写身体感受和心里话（“醒来第一反应不是期待，而是疲惫”），再写一次顿悟。亲历不能挤掉金句：同题对标《世界不是一个审判你的考场》完全没有亲历，靠密集的“你以为……其实……”和反差句撑满全片。
6. **悖论金句**：“判断越多，看见的可能性越少”“有些坚持送你上山顶，有些坚持只让你更擅长忍受错误”。
7. **比喻必须能画出来**：门、路、山顶、站在岸上 / 下水——比喻里的东西就是下一个画面。
8. **结尾重新定义一个常见词**：“所谓自由 / 年轻 / 衰老，不是……而是……”，比给建议更有余味。
9. **一个核心比喻贯穿全片**：开头立起来（目光像聚光灯），中段翻转（那束光是你自己打的），结尾收回（关掉 / 放下那束光）。
10. **挖一层“为什么”**：从现象挖到原因（怕被看 ← 自我审判 ← 要求自己完美），哲学深度来自这一层，最好能回扣开场悖论。
11. **实验和反差要具体**：实验写年份 / 学校、怎么做、两个数字；记忆反差用一个无关小细节收尾（别人记住的只是“那天天气不错”）。

## 二、画面：文字和素材怎么配

**先看这条（高原现象一期，对照江东陵三期前 30 秒逐秒帧）**：对标每帧元素并不多（2–6 个），画面却满，原因是：
1. **素材大、贴边、出画**：人物占满画面高度（h≈600–700），贴着底边甚至被画框裁掉，字幕直接压在人身上；场景抠图、冰山这类大物件也贴边。不要把人缩到半高悬在纸中间。
2. **一个场景停 12–24 秒，逐句叠加**：同一场景里椅子 → 女人 → 男人 → 气泡 → 挂历 → 桌子一句一句加上去，到后面一屏 4–6 个元素；不要每 4–6 秒就清屏换场。
3. **照片 + 抠图叠层**：全屏照片做底（极光、教室），上面压一个大人物或雕像抠图。
4. **文字少而大**：关键词 56–96 号，分列在物件两侧（确定 ◯ 控制）或人物之间；概念卡是唯一有意留白的画面。
5. 审图用 `scripts/perline_shots.py` 出逐句截图，而不是只看场景结尾帧。


- **逐字打出**：概念定义和核心金句用打字机效果整句逐字出现在画面上方，下面保留人物场景。
- **循环图 / 概念清单**：讲机制时画“付出 → 否定 → 自我怀疑”的红箭头循环；讲多个原因时逐条叠加“红字标题 + 括号定义”。
- **寓言完整演出来**：每句话一个动作（驴、两堆干草、思考乱线、倒下）。
- **分层叠加提升质感（约三分之一到一半的场景用）**：底层放一块沿轮廓抠出的**场景抠图**（建筑、山体、桥、舞台、大树），加一圈白色剪纸边，尺寸大、可以贴边或出框；上层叠人物或物件，压在场景一角，前后关系清楚。前后两句共用一个主体时，可以只换背景层。不是每个场景都要这样，单个抠图、文字卡、全屏照片照常穿插。
- **一个名词一个物件**：文案列举几个名词，画面就逐个叠加几个对应物件（关系 → 夫妻，工作 → 老电脑，生活 → 城市天际线）。
- **新元素节奏**：平均 1.5–3 秒出现一个新元素（约每条字幕一个），一个场景 5–12 秒，之后整体淡出换场。
- **画面饱满度**：大部分时间纸底上有 2–4 个元素，约占画面 40%–60%；只有概念卡是纯文字留白。我们第一期多数场景只有 1–2 个元素，偏空。
- **底部照片带**用在转折和金句处（城市、公路、山、泳池），给画面一个“地面”。
- **内心独白做气泡，而且用口语甚至网络梗**：旁白讲道理，气泡说大实话，形成幽默反差，这是我们第一期完全没有的。
- **列举用竖排彩色关键词**（每个词一种颜色），概念卡用“黑色引号概念词 + 红色两行定义”，停留 5–10 秒。
- **同一个人物贯穿一段**：作者亲历段用同一个剪影人物代表“作者”，换物件不换人。
- **素材风格**：复古人物抠图（上世纪中期）、古典雕像、老物件、图标（胶片、握笔手、思考云）、风景照片带混用；超现实组合（涂掉眼睛的肖像、眼球、戴墨镜的孩子）制造记忆点。
- **片尾**：对标账号用固定的片尾标记做账号识别。那是对方的标识，我们不照搬；我们自己的片尾标记待定。

## 五、写下一期时的检查清单

- [ ] 开场一句用 hooks.md 的 6 种写法之一，3 句内拆穿一次常识并给出代价
- [ ] 概念出现在 10%–25% 之间，前面有一次拆穿
- [ ] 至少一组“三连”，每一条都能画成一个物件
- [ ] 一段作者亲历（自称“我”；身体感受 + 心里话 + 顿悟），约占 10%–20%，不挤掉金句
- [ ] 一个核心比喻从开头贯穿到结尾
- [ ] 有一层“为什么”（现象背后的原因），最好回扣开场
- [ ] 1–2 句内心独白做成口语气泡，适当带一点幽默 / 网络用语（不要过量）
- [ ] 至少 2 个能画出来的比喻
- [ ] 一句悖论金句
- [ ] 结尾重新定义一个常见词
- [ ] 画面：每 2 秒左右一个新元素，每屏 2–4 个元素
