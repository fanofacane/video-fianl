# 制作经验沉淀

每期做完把新经验补进来。来源：我们做过的每一期 + 对标视频分析。

## 文案

- **字数按自己的音色算**：当前音色原速实测 4.3 字/秒（旧音色 4.6）（不含标点），对标账号约 5.0–5.3。按 6 字/秒估算会短 25%（刺猬法则原计划 90 秒，实际 70 秒）。90 秒 ≈ 370–410 字，这是参考范围，允许上下浮动，别为卡字数牺牲语句通顺。
- **标题就是第一句或结论句**：对标视频没有单独简介，简介 = 标题 + 4–5 个话题。
- **例子和心态要真实大众**（聚光灯效应第二稿被否）：“想躲起来的人”不是正常人的状态，“衣服溅油”太小众。写完每个例子问一句：一半以上的观众经历过吗？
- **开头要有对标的文笔**（边际效用一期，开头换了 5 批才定）：自己凭空写的金句式开头（“你越热情，就越廉价”）用户都不满意；读过对标原文、照着那种语气写才对味。出开头选项时可以标明借鉴了哪篇。
- **问句开头要接答案**：开头改成问句后，第 2 句要能回答它（“太宰治在《人间失格》里给过答案：”+ 原话），不能沿用陈述句时期的过渡句。
- **名言话题**：给的是一句名言时，名言放在开场作答案、下半句在正文中段再引一次（“太宰治还写过一句”），首尾都扣住出处。
- **封面别矫枉过正**（活在当下第一版被否）：不抄样张不等于扔掉样张的风格。双重曝光 / 移轴 / 拍立得这类图库风很丑；用对标那几种处理，换成本期的主体，就对了。
- **写稿最有效的方法是对着原文写**（高原现象、活在当下）：读认可稿和相近对标的原文、列仿写对照表再写，稿子一次通过；凭规范里的技巧清单或骨架写，每次都被否。
- **规范是参考，不是模板**（2026-10-28 用户指出）：规范曾两次变成模板（技巧清单、9 段骨架 + 必备句式），写出来千篇一律。每期的结构按内容来定。
- **活在当下一期画面一次通过**：每场景先铺场景层（斜切钟面、海平线、公路、长桥、站台），人名年份竖排，一句一个元素叠加，出逐句截图自查。

## 画面

- **画面空的主因**：素材小、悬在纸中间、每 4–6 秒清屏换场。现在的做法见 body-writing.md 第二节（场景层、大元素贴边、一个场景停 10–20 秒逐句叠加）。
- **封面**：不能照搬样张，也不能扔掉样张的风格；见 script-style.md 第 7 节。

- **结尾可以回扣开场画面**：用和封面同场景的照片（不带封面人物，以免裁出怪影）做照片带，首尾呼应。
- **版面安全区**（已修正）：字幕在 y≈610–680。人物**可以**贴底出画、让字幕压在身上（对标都是这样）；不要为了躲字幕把人缩小悬在中间，那是画面空的主因。屏幕文字放上半部，别压在人物脸和头发上；气泡贴着说话的人。
- **开场到正文**：用“提亮溶解”（fadewhite），浅色纸底接得自然。

## 流程与效率

- **改稿先重新确认，不自动重配音**：稿件确认绑定内容版本。只有显式 `--voice` 才调用 MiniMax；`--shots` 和成片入口仅读取完成记录。旧配音按版本保留，不删除，不拿旧音频配新文案。
- **生图偶尔被当成“改图”请求退回**（返回“请上传原图”）：提示词开头加“生成一张全新的图片：”即可。
- **字压照片看不清**：照片上不要直接放屏幕文字，改成“上半纸底放字 + 下半撕边照片带”。
- **先截图后渲染**：正文截图几秒出，碎片开场 3D 渲染约 10 分钟；用户审正文截图的同时，后台先渲染开场（开场不依赖正文）。
- **一切都缓存**：配音、对齐结果、素材、碎片帧都按内容缓存在 `output/`，改画面不会重新配音或重新生图，避免重复计费。
- **音色与语速**（2026-10-26 起）：默认音色 `video_narrator_20261026`、原速 1（试过 0.9：约 3.9 字/秒，461 字配出 118 秒，太长，已改回），都在 `.env`（`MINIMAX_VOICE_ID`、`MINIMAX_SPEED`）。换音色或语速后每秒字数会变，要用整稿重测（新音色原速已测为 4.3 字/秒）。
- **换音色、调语速要先拿同一段台词对比试听**：同一段文字分别用新旧音色配，用户才好判断；文字里的标点会产生停顿，对比原音频时要按原音频断句或去掉标点。
- **配音只合成一次**：先把逐字稿定稿再配音；中文全文变化时，重新确认后显式合成新版本。只改分行或英文字幕可复用音频，分行变化会重新做本地对齐。失败请求保留记录，核实结果前不自动重试。

## 技术坑

- **MiniMax 字幕时间太粗**（十几秒一段）→ 用本地 Whisper 逐字时间 + 文案匹配做逐行对齐（`video/align.py`）。
- **生图接口有时只返回图片链接**，而且下载常被中断 → 只重试下载，不重新生图（不重复计费）。
- **透明底素材要检查 alpha**：生成后确认有透明像素再用；不合格就重新生成，别拿白底图凑合。
- **media-parser 技能的 `client.mjs` 顶层 await 与 `workflows.mjs` 循环引用会卡死**（exit 13），已修复；更新技能时注意。
- **服务器安全检查偶尔不返回结果**，命令会被拦下：等一会儿重试，不是代码问题。
