# 逐字稿写作规范

每期写稿严格按本文执行。依据：参考库 10 个对标视频（两个账号）的口播与逐秒画面分析，以及江东陵作品列表的封面与标题。
本文总结写法规律；写稿时可以引用、化用对标视频里合适的句子和段落。

**动笔前**：先逐篇仔细读 [library/four_transcripts.md](../library/four_transcripts.md)，学对标的文笔；再读 [hooks.md](hooks.md)（开头与前 30%）和 [body-writing.md](body-writing.md)（正文写法与画面配合），再读参考库 `library/reference/` 中与本期话题最接近的 1–2 个对标视频（`breakdown.md` + 逐秒帧）。

## 1. 规格

| 规格 | 时长 | 字数（不含标点） | 用途 |
| --- | --- | --- | --- |
| **90 秒版（默认）** | 85–95 秒 | **400–440 字** | 每期默认 |
| 短版 | 60–70 秒 | 280–320 字 | 话题轻、只讲一个场景时 |
| 长版 | 3–3.5 分钟 | 830–970 字 | 需要讲人物、理论多层展开时 |

字数按**复刻音色实测语速 4.6 字/秒**（不含标点、含自然停顿）换算。对标账号语速约 5.0–5.3 字/秒，比我们快，不能照搬它们的字数。交稿前用脚本数一遍去标点后的字数。

## 2. 写法约定（已和用户确定）

- **作者自称“我”**，作者亲历段约占全片 10%–20%：短、具体、有一个意外转折，不挤掉金句。
- **概念位置和对标一样**：在全片 10%–25% 处出现（开场一句 + 一次“你以为……其实……”之后），用一句话定义或一个核心比喻点明，紧接一个最小生活场景。
- **一个核心比喻贯穿全片**：开头立、中段翻转、结尾收回（见 body-writing.md 第 9 条）。开头与前 30% 的写法见 [hooks.md](hooks.md)。
- **幽默气泡适当加入**：每期 1–2 处，把内心独白写成口语、可带一点网络用语，与严肃旁白形成反差；不要每个场景都搞笑。
- **开场一句**：用 [hooks.md](hooks.md) 的 6 种写法之一（反常识断言、祈使句、悖论、条件后果、比喻、问句），以断言为主；这一句就是封面字幕和发布标题。
- **可以借鉴**：对标视频里好的句子、比喻、段落可以适当引用或改写，再结合我们自己的例子和经历。

## 3. 90 秒版结构骨架（约 420 字）

| 段落 | 句数 | 写法 | 放在哪里 |
| --- | --- | --- | --- |
| 1. 开场一句 + 拆穿 | 3 | 反常识断言（6 种写法见 hooks.md）；“我们总以为……可现实却是……” | 碎片开场里念（约 6–8 秒） |
| 2. 扩大范围 + 情绪 | 2–3 | 三项列举或数量递进，落到情绪词 | 约 8–18 秒 |
| 3. 概念 | 2 | “心理学里有个概念，叫……简单来说……” | 约 10%–25% |
| 4. 证据 / 场景 | 3–4 | 具体实验（年份或学校 + 做法 + 两个数字）或一件小事 + 直接引语 | 约 25%–45% |
| 5. 反转 | 2–4 | 连续“你以为……其实……”，第二个“其实”把镜头转向别人 | |
| 6. 作者亲历 | 3–5 | “我以前……”：具体时刻 + 身体反应 + 意外结果（气泡）+ 一句记忆反差 | 约 10%–20% |
| 7. 深层原因 | 3–4 | 挖一层“为什么”，回扣开场悖论；核心比喻在这里翻转 | |
| 8. 排比 | 2 | “你可以……可以……但不必……” | |
| 9. 重新定义收尾 | 2–3 | “所谓【常见词】，不是……而是……”，最后一句可单独截图 | 结尾 |

短版：去掉作者亲历，处境三连换成一个具体场景（动作 + 原话）。
长版：在 3 和 4 之间加“权威人物观点”和第二层追问，处境和场景各两组。

## 4. 句子规则

- **一句一画面**：每个分句 6–16 字，就是一条字幕；一个完整句不超过 3 个分句。
- **对观众说“你”**，作者段说“我”；少用书面连接词，多用“其实、往往、反而、所以你会发现”。
- **高频句式**（每篇至少用 5 种）：
  - 断言：“X，其实只有……”
  - 纠偏：“不是……，而是……”
  - 递进：“你以为……，其实……”
  - 三连：“越……越……”“像是在……”三次同构
  - 画像：“能……却……”“知道……却没有……”
  - 悖论：“……越多，……反而越少”
  - 对仗：“有些……，有些……”“不是所有……，也不是所有……”
  - 重新定义：“所谓……，不是……，而是……”
- **例子要大众、高频、真实**：选大多数人一周内就会遇到的事（冒痘、发言卡壳、打招呼没人应、上台讲话），不要小众情境（衣服溅油），也不要编一种正常人不会有的心态（“想躲起来”）。观众要能立刻说“这不就是我”。
- **具体名词**：多用能直接画出来的物件和场景词（钱、手机、两个小时、会议室、考场）。
- **比喻要能画出来**：门、路、山顶、岸边 / 下水，比喻里的东西就是下一个画面。
- **结尾不说教**：不用“所以我们要……”，改为重新定义一个词或描述一个新视角。

## 5. 逐字稿交付格式

每一行是一条字幕，并标注画面提示，直接驱动正文场景：

```
[开场] 极度自卑者，其实就是极度自信者 | 开场：碎片拼合，大字“聚光灯效应”
[开场] 因为他觉得人们都在看着他 | 开场：人物周围浮现目光
[概念] 别人的目光像聚光灯一样 | image: 舞台顶灯照向人物
[三连] 你今天头发没洗，觉得全世界都看出来了 | image: 头发凌乱的人 + 周围的眼睛
[三连] 你上台说错一句话，觉得所有人都记住了 | image: 台上人物 + 台下观众
[三连] 仿佛别人正在开会，研究你的愚蠢 | bubble(white): “他们是不是还在讨论我？”
[反转] 但真相是，没有那么多人在看你 | text(typewriter): “没有那么多人在看你”
[机制] 你以为是别人在审视你 | image: 四周的目光指向人物
[机制] 不，是你自己在审判自己 | image: 人物面对镜子里的自己
[结尾] 所谓成长，就是慢慢关掉那束不存在的聚光灯 | image: 逐渐熄灭的聚光灯
...
```

画面元素（`video/body/build.py` 实际支持的类型）：

| 类型 | 用途 |
| --- | --- |
| `image` | 透明底抠图：人物、物件、雕像、图标、**场景抠图**（建筑 / 山体 / 舞台，沿轮廓抠出）；`h` 按高度或 `w` 按宽度缩放，`border` 加白色剪纸边，`flip` 翻转，可超出画框 |
| `strip` | 底部撕边照片带（转折、金句、风景） |
| `photo` | 全屏照片（情绪高点，停 2–4 秒） |
| `text` | 屏幕文字：概念词、定义、关键词、公式、金句；`"typewriter": true` 逐字打出 |
| `bubble` | 对话气泡：`green` 绿底聊天框 / `white` 白底漫画气泡 |
| `list` | 概念清单：逐条叠加“红字标题 + 括号说明” |
| `cycle` | 循环图：几个词绕一圈，红色弧形箭头逐个连起来 |

## 6. 示例（聚光灯效应，最新逐字稿）

主题：聚光灯效应｜封面大字：聚光灯效应｜发布标题：极度自卑者，其实就是极度自信者

> 极度自卑者，其实就是极度自信者，因为他觉得人们都在看着他。
> 我们总是不由自主地认为，别人的目光像聚光灯一样，时刻追随着自己，精准地捕捉我们的窘迫、不安和失败。
> 你今天头发没洗，觉得全世界都看出来了；
> 你上台说错一句话，觉得所有人都记住了；
> 你在群里发了一句不太得体的话，整晚翻来覆去，仿佛别人正在开会，研究你的愚蠢。
> 但真相是，没有那么多人在看你。
> 1999 年，心理学家基洛维奇和萨维茨基曾做过一个实验，让受试者穿上极其尴尬的 T 恤进入人群。
> 受试者认为，至少有一半人会注意到这件衣服，但实际上，只有不到 20% 的人抬头看了一眼。
> 你以为别人盯着你的缺点，其实别人也在盯着自己的缺点。
> 你以为自己是众人审视的对象，可在别人的世界里，你可能只是一个一闪而过的背景音。
> 每个人都活在自己的主观剧场里，每个人都以为自己是主角，也因此高估了自己在他人心中的戏份。
> 但其实，很多人连自己昨天中午吃了什么都记不清，更不会记得你的尴尬瞬间。
> 你可能记得自己五年前说错的一句话，可当时在场的人可能早就忘了；
> 你记得自己某次出丑的表情，可别人记住的，也许只是那天天气不错。
> 那些让你蜷缩的他人的目光，其实是你自己内心聚光灯的倒影。
> 你以为是别人在审视你，不，是你自己在审判自己。
> 而过度审判的背后，恰恰是一种过度期待：你期待自己完美无瑕，所以你认定他人也在期待你完美无瑕。
> 世界不是一个审判你的考场，更多时候，它只是一个人来人往的广场。
> 有人看你一眼，有人与你擦肩，有人短暂停留，然后继续回到自己的生活。
> 所以，不要再把别人的眼睛装进自己的脑子里。
> 你可以紧张，但别把紧张当预言；
> 你可以不完美，但别因为不完美就拒绝出场。
> 所谓成长，就是慢慢关掉那束不存在的聚光灯，然后发现，原来你不是被所有人盯着，你只是终于可以开始走自己的路。

## 7. 发布标题、封面与简介

**封面画面风格（只用这两种，每期两种各出 1–2 张供选择）**

| 风格 | 标准样张 | 特点 |
| --- | --- | --- |
| ① 超现实艺术时尚摄影 | 对标账号主页封面（及时止损、他者性、情绪成本、认知闭合等） | 70 年代复古胶片、高饱和撞色（钴蓝天空 + 金黄麦田 / 翠绿草坡 / 红色花田）；单人居中，脸被遮挡或变形；一个与概念相关的怪异道具 |
| ② 蓝调安静写实 | 我们的《刺猬法则》封面（雪原长椅两端各坐一人） | 蓝调时刻、柔和冷色、空旷的自然场景；人物小比例背影；**构图本身就是概念的隐喻**（距离、留白、对称） |

**不要用**：暗调剧场、夜晚街头、黑背景舞台这类压抑的暗调电影画面（聚光灯效应第一版封面就是这类，已否决）。

共同要求：
- 主体在画面正中，上半部中间留干净天空或纯色区域给白色标题。
- 主页网格只显示正中竖版裁切（约 3:4），主体和标题都要落在正中；交稿时附竖版裁切预览。
- 提示词开头：①“超现实主义艺术时尚摄影，70 年代复古胶片质感，高饱和撞色，16:9 横幅；” ②“电影感写实摄影，16:9 横幅，蓝调时刻，柔和冷色调，低饱和，空旷安静，细腻胶片颗粒；”，后接“主体必须位于画面正中央，画面上半部中间留出大面积干净的天空区域用于放置白色标题；不要任何文字、水印、logo。”+ 场景描述。

**封面（碎片开场拼合后的画面）**
- 大字 = **概念词，2–5 字**：心理学词，或更有分量的哲学词（他者性、上手性、情绪成本、创伤后成长），或大众熟词（及时止损、热爱生活）。
- 大字下方的字幕 = **口播第一句**：反常识断言，能单独成立、够“扎心”（结构如“你的 A 比你的 B 更……”“X 不会留住 Y”“并不是……才是……”）。
- 高赞规律：概念词冷门有分量 + 第一句反常识。

**发布标题**
- 默认 = **口播第一句或全片结论句**，以陈述句为主；问句偶尔用；也可以极简（两个字的态度词）。
- 25 字以内，口语、有画面；不写概念名（概念放封面和话题里）。
- 每期给 3 个备选：① 第一句断言 ② 结论句 ③ 问句版，标明推荐。

**简介**：没有单独的简介，直接复制 `发布标题 #话题1 #话题2 #话题3 #话题4 #话题5`。
话题顺序：`#哲学` `#心理学`（领域）→ `#概念名` → 1–2 个场景词 → 1 个泛流量词（`#抖音精选` `#深度思考` `#自我成长`）。

## 8. 交稿前自查

- [ ] 第一句属于 hooks.md 的 6 种写法之一，能直接当封面字幕和发布标题
- [ ] 有一组处境三连，每条都能画成一个物件
- [ ] 有作者亲历（自称“我”）：具体时刻 + 身体反应 + 意外转折，约占 10%–20%
- [ ] 一个核心比喻贯穿开头、中段、结尾；有一层“为什么”
- [ ] 处境三连写夸张心理；实验写具体（年份 / 学校 + 数字）
- [ ] 1–2 句内心独白做成口语幽默气泡，不过量
- [ ] 概念在全片 10%–25% 处出现（一句话定义或核心比喻）
- [ ] 至少 5 种高频句式，至少 2 个能画出来的比喻，1 句悖论或对仗金句
- [ ] 结尾重新定义一个常见词，不说教
- [ ] 每个分句不超过 16 字
- [ ] 字数符合规格（90 秒版 400–440 字，不含标点）
- [ ] 附 3 个发布标题备选 + 话题标签 + 封面大字
