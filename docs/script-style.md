# 逐字稿写作规范

每期写稿严格按本文执行。本文依据：江东陵、得一两个账号的口播分析、用户认可的逐字稿（`library/reference/`），以及我们自己被否和通过的稿子。

> **为什么重写（2026-10-27）**：旧版规范是从最早几期总结的“技巧清单”——处境三连写夸张心理、每期 1–2 个网络梗气泡、编一段带意外转折的作者亲历、反复“你以为……其实……”、每篇凑 5 种句式。照着写出来是段子腔，每期都要用户再给一个参考视频才写对。真正写对的一版（高原现象）是**逐段对着江东陵的转写稿仿写**出来的。所以本规范把重点放在“文笔”和“仿写对照”，技巧清单全部作废。

## 0. 动笔前（必做，缺一不可）

1. **读范文**：逐篇读 `library/reference/` 下全部认可稿（我们自己写、用户认可的标准答案），再看 `docs/hooks.md` 的对标原句表。
2. **写仿写对照表**（交稿时一起给用户看）：把本期每一段对应到认可稿或对标原句里的某一步，写出原句和我们的句子，例如：

   | 段 | 对标原句（来源） | 我们的句子 |
   | --- | --- | --- |
   | 开头 | 人生很多问题不是用来解决的，而是用来接受的（江东陵·强迫性思维） | 很多成长不是一点一点发生的，而是在某一天突然发生的 |
   | 共鸣 | 人最难承受的往往不是一个坏结果，而是事情悬在那里 | 人最难承受的，往往不是辛苦，而是付出之后看不到任何回应 |

   对不上任何一步的段落，要么删，要么说清楚为什么需要它。
3. **找一个真实依据**：心理学 / 哲学概念 + 一个真实研究或真实出处（年份、人名、做法、结果）。查不到就不要编；用安静的生活小场景代替。

## 1. 规格

| 规格 | 时长 | 字数（不含标点） | 用途 |
| --- | --- | --- | --- |
| **90 秒版（默认）** | 85–95 秒 | **约 370–410 字** | 每期默认 |
| 短版 | 60–70 秒 | 260–300 字 | 话题轻、只讲一个场景时 |
| 长版 | 3–3.5 分钟 | 770–900 字 | 需要讲人物、理论多层展开时 |

字数按**当前音色 `video_narrator_20261026` 原速实测 4.3 字/秒**（不含标点、含自然停顿；2026-10-26 实测 461 字 106 秒）换算。旧音色是 4.6 字/秒。对标账号语速约 5.0–5.3 字/秒，比我们快，不能照搬它们的字数。交稿前用脚本数一遍去标点后的字数。表中字数是参考范围，允许上下浮动；语句通顺优先，不必为卡字数删改句子。

## 2. 文笔（最重要）

像一个想清楚了的人，平静地跟朋友慢慢讲一件事。不是讲段子，不是喊口号。

- **从人心里真正的需要和恐惧写起**：“人最难承受的，往往不是……而是……”“一个人真正想要的，并不一定是答案，而是答案带来的确定感”。
- **一层层往下挖**：用“因为”“也就是说”“原来”“恰恰”“往往”“未必”把道理推深一层，至少挖到“为什么”。
- **对称的句子**：“不是……而是……”“有些人……有些人……”“A 和 B，其实是两回事”“你可以理解……却不必……”。
- **克制、不绝对**：至少一句限定——“当然，不是所有……”“我也不认为……”。这是可信感的来源。
- **例子要安静、真实**：一个真实研究（年份 + 人名 + 做法 + 结果），或一两个极小的生活瞬间（遇到一只小猫下意识想分享、习惯性打开聊天窗口、学会骑车就回不到不会骑）。**不写**段子式三连、夸张心理、网络梗气泡。
- **作者只出观点，不编故事**：“我一直觉得 / 我越来越觉得……最难的地方不是……而是……”。不要编“我以前……结果第二天……”的亲历。
- **结尾温和**：给一个新视角或一种许可（“问题也许还在那里，但你已经可以越过它”“有些人的哀伤发生在离开之前，有些人发生在失去之后”）；可以回扣开头；不用“所以我们要……”。
- **用词平实**：少用华丽形容词和网络词；书面但口语能念顺。

## 3. 90 秒版段落骨架（约 390 字）

| 段 | 句数 | 写法 | 对标出处示例 |
| --- | --- | --- | --- |
| 1. 开头 | 2 | 问句“为什么很多人……，却……呢？”/ 判断句“X 不是用来 A 的，而是用来 B 的”/ 先引一句流行说法再拆 / 祈使“不要……”，**第 2 句回答或延伸第 1 句** | 得一·真心待人；江东陵·强迫性思维、迟发性哀伤、行动化 |
| 2. 共鸣 | 2–3 | 我们几乎每个人都经历过的处境 → “人最难承受的往往不是……而是……” | 江东陵·强迫性思维 |
| 3. 概念 | 2–3 | “心理学中有一个概念，叫做 X。它指的是……”，必要时补“简单来说” | 江东陵·迟发性哀伤；得一·知识诅咒 |
| 4. 证据 | 3–4 | 真实研究：年份 + 人名 + 怎么做 + 结果；或两个安静的小场景 | 得一·知识诅咒（伊丽莎白·牛顿敲节奏实验） |
| 5. 挖一层 | 2–3 | “原来 / 也就是说，……不是……而是……” | 江东陵·强迫性思维 |
| 6. 现实里的我们 | 2–3 | 我们怎么误读它，于是“恰恰”…… | 江东陵·延迟满足 |
| 7. 作者观点 | 2 | “我一直觉得，……最难的地方不是……而是……” | 江东陵·迟发性哀伤 |
| 8. 限定 | 1–2 | “当然，不是所有……”，给出判断标准 | 江东陵·行动化 |
| 9. 收尾 | 2–3 | 新视角或许可，温和；可回扣开头 | 江东陵·强迫性思维 |

概念大约在 15%–25% 处出现。短版去掉 6、7；长版在 4 后加第二个例子、在 5 后加第二层“为什么”。

## 4. 句子规则

- 一行一条字幕；一行最好不超过 20 字，超过就拆成两行（逗号处断开）。
- 对观众说“你 / 我们 / 很多人”，作者观点说“我”。
- 字数按第 1 节估算；交稿前用脚本数去标点后的字数。
- 写完大声读一遍：**像不像江东陵本人在念？** 哪一句像短视频段子、像鸡汤口号，就改掉。

## 5. 逐字稿交付格式

每一行是一条字幕，并标注画面提示，直接驱动正文场景（示例格式，内容以第 6 节为准）：

```
[开场] 极度自卑者，其实就是极度自信者 | 开场：碎片拼合，大字“聚光灯效应”
[开场] 因为他觉得人们都在看着他 | 开场：人物周围浮现目光
[概念] 别人的目光像聚光灯一样 | image: 舞台顶灯照向人物
[三连] 你今天头发没洗，觉得全世界都看出来了 | image: 头发凌乱的人 + 周围的眼睛
[三连] 你上台说错一句话，觉得所有人都记住了 | image: 台上人物 + 台下观众
[三连] 仿佛别人正在开会，研究你的愚蠢 | bubble(white): “他们是不是还在讨论我？”
[反转] 但真相是，没有那么多人在看你 | text(typewriter): “没有那么多人在看你”
[机制] 你以为是别人在审视你 | image: 四周的目光指向人物
[机制] 不，是你自己在审判自己 | image: 人物面对镜子里的自己
[结尾] 所谓成长，就是慢慢关掉那束不存在的聚光灯 | image: 逐渐熄灭的聚光灯
...
```

画面元素（`video/body/build.py` 实际支持的类型）：

| 类型 | 用途 |
| --- | --- |
| `image` | 透明底抠图：人物、物件、雕像、图标、**场景抠图**（建筑 / 山体 / 舞台，沿轮廓抠出）；`h` 按高度或 `w` 按宽度缩放，`border` 加白色剪纸边，`flip` 翻转，`rotate` 旋转（做斜切进画面的场景层），可超出画框 |
| `strip` | 底部撕边照片带（转折、金句、风景） |
| `photo` | 全屏照片（情绪高点，停 2–4 秒） |
| `text` | 屏幕文字：概念词、定义、关键词、公式、金句；`"typewriter": true` 逐字打出 |
| `bubble` | 对话气泡：`green` 绿底聊天框 / `white` 白底漫画气泡 |
| `list` | 概念清单：逐条叠加“红字标题 + 括号说明” |
| `cycle` | 循环图：几个词绕一圈，红色弧形箭头逐个连起来 |

所有元素默认退场时**向下移动并淡出**（`"exit": "down"`）；照片和照片带默认原地淡出（`"exit": "fade"`）。人名、年份可用竖排红字（`text` 里每个字之间加 `\n`）。

## 6. 示例（高原现象，用户认可的定稿）

开头：为什么很多人付出了努力，却迟迟等不来改变呢？（发布标题用陈述句：很多成长不是一点一点发生的，而是在某一天突然发生的）

> 为什么很多人付出了努力，却迟迟等不来改变呢？
> 因为很多成长不是一点一点发生的，而是在某一天突然发生的。只是在那之前，你要先熬过一段毫无变化的日子。
> 而人最难承受的，往往不是辛苦，而是付出之后，看不到任何回应。
> 心理学中有一个概念，叫做高原现象。它指的是练习到某个阶段，进步会突然停滞，像走上了一片平坦的高原。
> 1897 年，布赖恩和哈特研究电报员学发电码，发现他们的速度会长时间停滞不前，然后在某一天，突然跃升到一个新的水平。
> 原来高原期并不是没有进步，而是大脑正在悄悄重组：从一个字母一个字母地听，变成整个单词地听。
> 也就是说，你看不到变化，不是因为什么都没发生，而是变化正发生在你看不见的地方。
> 可我们太习惯用结果来确认努力，看不到回报，就开始怀疑方向，怀疑自己，于是很多人，恰恰停在了快要越过高原的时候。
> 我一直觉得，高原期最难熬的地方不是累，而是安静，安静到让你以为，自己被世界忘记了。
> 当然，不是所有停滞都意味着突破，有时方向真的错了，需要的是调整，而不是硬撑。真正重要的，是分清自己在原地打转，还是在积蓄力量。
> 如果是后者，就不必急着向这段日子要答案。它也许不会立刻奖励你，但总有一天，会把你送到一个新的地方。

## 7. 发布标题、封面与简介

**封面：沿用对标的视觉语言，主体按本期原创**

> 两次教训：①（高原现象）把 `docs/reference/covers/` 四张对标当模板，主体、构图、场景几乎照搬，换话题封面都一样。②（活在当下第一版）为了“不一样”把风格也扔了，做成双重曝光、移轴微缩、拍立得这类商业图库风，又杂又俗，被否。正确做法是：**画面处理（风格）借鉴对标，画里的主体和场景按本期稿子原创**。

可用的画面处理（都来自对标，质感要达到样张水平）：失焦动态模糊胶片、朴素派油画平涂 + 故障拖影、黑白电影、黑底古典铜版画、70 年代超现实时尚摄影、蓝调安静写实。不要用双重曝光、移轴微缩、商业写实摄影这类图库风。

做法：
1. **从本期稿子里找视觉隐喻**：列 5 个。例：活在当下 → 站台上向前后拖出残影的人、坐在饭桌前心思被拖走的人、伸手够不到奔跑小孩的老人的手、站在沙漏细腰处的小人。
2. **每个隐喻配一种对标的画面处理**，3–4 张各用一种；**主体、构图、场景不能和样张雷同**（样张是：晚霞里两个背影、绿丘上相拥的人、海边女子剪影、对称的骑士版画）。
3. **画面简洁**：一个主体、浓郁的气氛，提示词里写明“画面简洁，只有一个主体，气氛浓郁，有艺术感”。
4. **每张写一句“它在说什么”**，交稿时附上；说不出来就是没扣题。
5. **换题检验**：把大字换成别的概念，这张图还成立吗？成立就太泛，重做。

画面要求：
- 大字可以直接压在主体上，不必留空天空；主体大致居中（主页网格只显示正中约 3:4）；交稿附竖版裁切或宫格对比。
- 暗调可以用，但要有艺术质感；不要廉价的暗调剧场 / 夜街 / 黑舞台。
- 提示词开头写“生成一张全新的图片：16:9 横幅，不要任何文字、水印、logo。”，后接处理手法 + 隐喻场景。

**封面文字（碎片开场拼合后的画面）**
- 大字 = **概念词，2–5 字**：心理学词，或更有分量的哲学词（他者性、上手性、情绪成本），或大众熟词。
- 大字下方的字幕 = **口播第一句**（问句或判断句都可以）。

**发布标题**
- **用陈述句**（用户不喜欢问句标题）：第一句是判断句就直接用；第一句是问句，就用第 2 句的回答或全片结论句。
- 25 字以内；不写概念名（概念放封面和话题里）。每期给 3 个备选，标明推荐。

**简介**：没有单独的简介，直接复制 `发布标题 #话题1 #话题2 #话题3 #话题4 #话题5`。
话题顺序：`#哲学` `#心理学`（领域）→ `#概念名` → 1–2 个场景词 → 1 个泛流量词（`#抖音精选` `#深度思考` `#自我成长`）。
