# 文案风格模版（逐字稿写作规范）

生成逐字稿时按本文执行。依据：6 个同类参考视频（两个账号）的口播转写与画面分析。
只总结写法规律；下方示例均为本项目原创，不使用参考视频原文。

写稿前先读参考库 `library/reference/*/breakdown.md`，挑 1–2 个结构最接近本期话题的对标视频做底稿结构。

## 1. 规格（默认 90 秒版）

| 规格 | 时长 | 字数（不含标点） | 结构 |
| --- | --- | --- | --- |
| **90 秒版（默认）** | 85–95 秒 | **400–440 字** | 钩子 → 概念 → 寓言/场景 → 第二个场景 → 误解与点破 → 本质 → 排比 → 回扣金句 |
| 短版 | 60–70 秒 | 280–320 字 | 钩子 → 概念 → 一个场景 → 本质 → 金句 |
| 长版 | 3–3.5 分钟 | 830–970 字 | 钩子 → 概念 → 误解 → 机制 → 两个场景 → 作者视角 → 转折 → 排比 → 回扣开头 |

字数按**本项目复刻音色实测语速 4.6 字/秒**（不含标点、含自然停顿）换算；参考账号语速约 5.0–5.3 字/秒，比我们快，不能照搬它们的字数。
写完用 `python3 -c` 数一下去标点后的字数再交稿。

## 2. 结构骨架

### 90 秒版（约 420 字，默认）

1. **钩子（2 句）**：反常识问句，问题里有观众经历过的矛盾。这两句和概念句一起放进碎片开场里念。
2. **概念（2 句）**：“心理学里有个概念，叫【概念名】。”——念到概念名时，开场标题正好在画面上。
3. **寓言 / 原始场景（4–5 句）**：概念的出处或一个形象的小故事。
4. **生活场景（4–5 句）**：具体到动作和原话（适合对话气泡）。
5. **点破（2 句）**：“不是……而是……”。
6. **误解（2–3 句）**：“我们总以为……其实……”。
7. **本质（3 句）**：“很多……不是败给了……而是……”；“真正好的……并不是……而是……”。
8. **排比（2–3 句）**：“你可以……可以……但也要……”。
9. **回扣（3–4 句）**：回到寓言或开头的问题，以一句金句结束。

### 短版（约 380 字）

1. **钩子（1–2 句，约 40 字）**：用“为什么……却……”提出一个反常识的问题，问题里要有观众自己经历过的矛盾。
2. **概念（1 句）**：“心理学 / 哲学 / 社会学里有个概念，叫【概念名】。”紧跟一句一句话版的定义。
3. **场景（3–5 句，约 120 字）**：一个具体到动作和台词的生活片段（聚餐、考试、聊天、加班）。人物说的话用口语原话写出来，方便画面做对话气泡。
4. **点破（2–3 句）**：“因为当你……时，你以为是……，可……”揭示场景背后的心理机制。
5. **本质（2 句）**：“真正……的人，并不是……，而是……”
6. **金句收尾（1–2 句）**：可单独截图传播的一句话，最好呼应钩子。

### 长版（约 1200 字）

1. **开场比喻 / 钩子**：一个贯穿全片的比喻（把人生换算成一天、把关系比作房子……），或一个反常识问题。
2. **常见理解**：“很多人理解……，喜欢……”先摆出大众看法。
3. **概念与人物**：引出理论与提出者（弗洛伊德、阿德勒、弗洛姆……），用一两句讲清核心观点。
4. **机制展开**：分 2–3 层往下追问，“但如果继续往下追问……也许会发现……”
5. **场景 ×2**：每个场景都有具体人物、动作、对白。
6. **作者视角**：用第三人称自称讲一段自己的经历（“我以前也会……后来发现……”），拉近距离。
7. **转折**：“……当然重要，但如果一直停留在……”把理论推向行动。
8. **排比收束**：2–3 句同构句，“你可以……，却不必……”
9. **回扣开头**：重新使用开场比喻，给出新的理解，以一句长金句结束。

## 3. 句子规则

- **一句一画面**：每个分句 6–16 字，适合做一条字幕；一个完整句不超过 3 个分句。
- **口语化**：用“你”直接对观众说话；少用书面连接词，多用“其实、往往、反而、所以你会发现”。
- **高频句式**（每篇至少用 4 种）：
  - 提问：“为什么……，却……？”
  - 纠偏：“不是……，而是……”
  - 递进：“你以为……，其实……”
  - 定义：“所谓……，不是……，而是……”
  - 排比：“允许你……，允许你……，也允许你……”
  - 让步转折：“……当然重要，但……”
  - 对比：“明明知道……，却总是……”
- **数字和具体名词**：多用具体物件和场景词（钱、手机、两个小时、聚餐、考场），它们会直接变成画面素材。
- **概念词只出现在关键位置**：开头引出一次、中段解释一次、结尾回扣一次。
- **结尾不说教**：不用“所以我们要……”，改为描述一种状态或一个新视角。

## 4. 逐字稿交付格式

每一行是一条字幕，并标注画面提示，便于直接驱动正文场景模板：

```
[钩子] 为什么你越想证明自己 | collage: 人物抠图(独自站在舞台上)
[钩子] 反而越容易焦虑？ | collage: + 聚光灯
[概念] 心理学里有个概念 | concept: “聚光灯效应”
[概念] 叫聚光灯效应 | concept: + 定义(高估别人对自己的关注)
...
```

画面提示的模板名见 [reference/common-style.md](reference/common-style.md) 第 8 节：`concept / formula / keywords / collage / bubble / chat / photo / quote`。

## 5. 原创示例（短版，约 360 字）

主题：聚光灯效应

> 为什么你越想证明自己，反而越容易焦虑？
> 心理学里有个概念，叫聚光灯效应。
> 我们总以为，自己的一举一动，都在被别人仔细打量。
> 开会时你说错了一个词，脸一下子就红了，
> 一整个下午都在想：大家是不是都觉得我很蠢？
> 晚上躺在床上，你又把那句话在脑子里重放了十几遍。
> 可第二天你问同事，他一脸茫然：你说错什么了？
> 因为在别人的故事里，你只是一个路过的配角，
> 而在你自己的故事里，你却给每个小失误都打上了追光。
> 你以为别人在审视你，其实一直审视你的，只有你自己。
> 所以你会发现，很多焦虑并不来自外界的眼光，
> 而来自我们把自己放在了舞台正中央。
> 真正松弛的人，并不是不在乎别人，
> 而是明白，没有人会像你一样，盯着你的缺点看那么久。
> 你可以犯错，可以尴尬，可以说错话，
> 但不必把每一次小小的失误，都当成一场公开审判。
> 当你把聚光灯关掉，
> 才会发现台下的人，其实都在忙着照亮自己。

## 6. 自查清单

- [ ] 钩子是问题，且包含一个反常识的矛盾
- [ ] 概念名 + 一句话定义在前 15 秒内出现
- [ ] 至少一个具体到动作和对白的生活场景
- [ ] 至少 4 种高频句式
- [ ] 每个分句不超过 16 字
- [ ] 结尾金句能单独成立，并呼应开头
- [ ] 字数符合规格（短版 330–420，长版 1100–1300）
- [ ] 全文原创，不照搬任何参考视频的句子

## 7. 发布标题与简介

参考库 6 个对标视频的共同点：**没有单独的简介，简介就是“发布标题 + 4–5 个话题标签”**。

标题三种写法（每期给 3 个备选，标明推荐）：

| 写法 | 结构 | 参考库例子的结构 |
| --- | --- | --- |
| 反常识问句 | 为什么 + 你/一类人 + 行为 + 却/总是 + 结果？ | “你的真心待人为什么总是不被……？” |
| 时间对比问句 | 为什么曾经……后来却……？ | “为什么曾以为……后来却……？” |
| 结论判断句 | 不是 X，而是 Y / 一句温柔的安慰或比喻 | “人其实需要的不是……而是……” |

规则：
- 15–25 字；口语、有画面感；不堆砌形容词；标题里尽量不出现概念名（概念放话题里）。
- 标题最好就是逐字稿的第一句或结论句，开场画面和标题能对上。
- 话题 4–5 个，顺序：`#哲学`/`#心理学`（领域）→ `#概念名` → 1–2 个场景词（`#亲密关系` `#人际关系`）→ 1 个泛流量词（`#深度思考` `#自我成长` `#抖音精选`）。
- 简介直接复制：`发布标题 #话题1 #话题2 #话题3 #话题4 #话题5`。
