# 逐字稿写作规范

本文讲**怎么写**，不规定**写成什么样**。每期的结构、句式、长短按本期内容来定；下面的写法都是从对标和认可稿里总结的“常见做法”，用来参考和取舍，不是每期都要凑齐的模板。

**最好的参考永远是原文**：用户认可的逐字稿（`library/reference/`）和与本期相近的对标视频逐字稿。规范只是帮你读懂它们。

> 教训：旧版规范先后变成过两套模板——①“技巧清单”（处境三连写夸张心理、网络梗气泡、编作者亲历、凑 5 种句式），写出来是段子腔；②“9 段骨架 + 必备句式”（每期都“人最难承受的往往不是……”“当然，不是所有……”“我一直觉得……”），写出来千篇一律。两次都是把参考当成了模板。

## 0. 动笔前

1. **读认可稿**：`library/reference/` 下全部认可稿，体会语气、节奏和深度。
2. **读 1–2 篇相近的对标逐字稿**：选话题或气质相近的江东陵 / 得一视频，用 `python3 -m video.library ref <slug> <链接>` 下载转写到本地 `output/library/<slug>/transcript.txt`（不入库）；用户给了链接就用用户的。
3. **想清楚这期要讲的那一个道理**，以及它最自然的展开方式：有的题目适合从一个问题挖下去，有的适合先拆一句流行说法，有的适合一个实验讲到底，有的适合两位哲学家对照。
4. **写仿写对照表**（随稿交给用户）：列出本期哪些段落借鉴了哪篇认可稿或对标的哪一步、原句是什么。它的作用是让用户看到“站在了哪些好作品上”，**不要求每段都有出处**；自己写的段落标“自写”即可。
5. **真实依据**：用到研究、人名、引文，必须真实可查（年份、人名、做法、结果）；查不到就不写，换成一个安静的生活瞬间。

## 1. 规格

| 规格 | 时长 | 字数（不含标点） | 用途 |
| --- | --- | --- | --- |
| **90 秒版（默认）** | 85–95 秒 | **约 370–410 字** | 每期默认 |
| 短版 | 60–70 秒 | 260–300 字 | 话题轻、只讲一个场景时 |
| 长版 | 3–3.5 分钟 | 770–900 字 | 需要讲人物、理论多层展开时 |

字数按**当前音色 `video_narrator_20261026` 原速实测 4.3 字/秒**（不含标点、含自然停顿；2026-10-26 实测 461 字 106 秒）换算。旧音色是 4.6 字/秒。对标账号语速约 5.0–5.3 字/秒，比我们快，不能照搬它们的字数。交稿前用脚本数一遍去标点后的字数。表中字数是参考范围，允许上下浮动；语句通顺优先，不必为卡字数删改句子。

## 2. 文笔（对标和认可稿的共同气质）

像一个想清楚了的人，平静地跟朋友慢慢讲一件事。下面是这种气质常见的样子，**按需要用，不用每条都出现**：

- 从人心里真正的需要和恐惧写起，而不是从现象的表面写起。
- 一层层往下挖，讲到“为什么”，而不是停在“是什么”。
- 克制、不绝对，必要时给出边界（什么情况下这个道理不成立）。
- 例子安静、真实：一个真实研究，或一两个极小的生活瞬间；不写段子、不夸张、不编亲历。
- 作者可以出来说一句自己的看法，但不必每期都有。
- 结尾给一个新视角或一种许可，温和，不喊口号、不说教。
- 用词平实，书面但口语能念顺。

**要避免的**：段子式三连、网络梗、夸张心理、编造的亲历、口号式结尾、为了“像对标”硬塞固定句式。

## 3. 常见的展开方式（参考，不是骨架）

对标和认可稿里常见这些环节，**按本期内容挑选、调整顺序、合并或省略**：

| 环节 | 常见写法 | 出处举例 |
| --- | --- | --- |
| 开头 | 一个问题、一句判断、一句流行说法或名言，后面常跟一句接住它的话 | 见 [hooks.md](hooks.md) |
| 共鸣 | 大多数人经历过的处境、心里的感受 | 江东陵·强迫性思维 |
| 概念 | 点出心理学 / 哲学概念，并用白话说清 | 得一·知识诅咒 |
| 依据 | 真实研究或哲学家原话，或生活小场景 | 得一·知识诅咒（牛顿敲节奏实验）；认可稿·心智游移 + 帕斯卡 |
| 挖深 | 现象背后的原因，真正的需要是什么 | 江东陵·强迫性思维 |
| 回到生活 | 我们平时怎么误读、怎么做 | 江东陵·延迟满足 |
| 边界 | 这个道理不适用的情况 | 江东陵·行动化 |
| 收尾 | 新视角、许可，或回扣开头 | 认可稿·活在当下 |

概念一般不要拖太晚出现，但没有固定百分比；一个实验讲透可以占一半篇幅，两位哲学家对照也可以没有实验。

## 4. 句子与字幕

- 一行一条字幕；一行最好不超过 20 字，超过就在逗号处拆成两行。
- 字数按第 1 节估算；交稿前用脚本数去标点后的字数。
- 写完大声读一遍：像不像一个认真的人在讲话？哪一句像段子、像口号、像在套句式，就改。

## 5. 逐字稿交付格式

交稿给用户：逐字稿（一行一条字幕）+ 仿写对照表 + 3 个标题 + 封面。画面设计在截图阶段做，不必在稿子里标注。

画面元素（`video/body/build.py` 实际支持的类型）：

| 类型 | 用途 |
| --- | --- |
| `image` | 透明底抠图：人物、物件、雕像、图标、**场景抠图**（建筑 / 山体 / 舞台，沿轮廓抠出）；`h` 按高度或 `w` 按宽度缩放，`border` 加白色剪纸边，`flip` 翻转，`rotate` 旋转（做斜切进画面的场景层），可超出画框 |
| `strip` | 底部撕边照片带（转折、金句、风景） |
| `photo` | 全屏照片（情绪高点，停 2–4 秒） |
| `text` | 屏幕文字：概念词、定义、关键词、公式、金句；`"typewriter": true` 逐字打出 |
| `bubble` | 对话气泡：`green` 绿底聊天框 / `white` 白底漫画气泡 |
| `list` | 概念清单：逐条叠加“红字标题 + 括号说明” |
| `cycle` | 循环图：几个词绕一圈，红色弧形箭头逐个连起来 |

所有元素默认退场时**向下移动并淡出**（`"exit": "down"`）；照片和照片带默认原地淡出（`"exit": "fade"`）。人名、年份可用竖排红字（`text` 里每个字之间加 `\n`）。

## 6. 范文

见 `library/reference/`（用户认可的逐字稿，含仿写对照表）。不在本文重复，避免把某一篇当成唯一模板。

## 7. 发布标题、封面与简介

**封面：沿用对标的视觉语言，主体按本期原创**

> 两次教训：①（高原现象）把 `docs/reference/covers/` 四张对标当模板，主体、构图、场景几乎照搬，换话题封面都一样。②（活在当下第一版）为了“不一样”把风格也扔了，做成双重曝光、移轴微缩、拍立得这类商业图库风，又杂又俗，被否。正确做法是：**画面处理（风格）借鉴对标，画里的主体和场景按本期稿子原创**。

对标常用的画面处理（质感要达到样张水平）：失焦动态模糊胶片、朴素派油画平涂 + 故障拖影、黑白电影、黑底古典铜版画、70 年代超现实时尚摄影、蓝调安静写实；同样有艺术质感的其他处理也可以。不要双重曝光、移轴微缩、商业写实摄影这类图库风。

做法：
1. **从本期稿子里找视觉隐喻**：先列几个。例：活在当下 → 站台上向前后拖出残影的人、坐在饭桌前心思被拖走的人、伸手够不到奔跑小孩的老人的手、站在沙漏细腰处的小人。
2. **每个隐喻配一种合适的画面处理**，3–4 张尽量各不相同；**主体、构图、场景不能和样张雷同**（样张是：晚霞里两个背影、绿丘上相拥的人、海边女子剪影、对称的骑士版画）。
3. **画面简洁**：一个主体、浓郁的气氛，提示词里写明“画面简洁，只有一个主体，气氛浓郁，有艺术感”。
4. **每张写一句“它在说什么”**，交稿时附上；说不出来就是没扣题。
5. **换题检验**：把大字换成别的概念，这张图还成立吗？成立就太泛，重做。

画面要求：
- 大字可以直接压在主体上，不必留空天空；主体大致居中（主页网格只显示正中约 3:4）；交稿附竖版裁切或宫格对比。
- 暗调可以用，但要有艺术质感；不要廉价的暗调剧场 / 夜街 / 黑舞台。
- 提示词开头写“生成一张全新的图片：16:9 横幅，不要任何文字、水印、logo。”，后接处理手法 + 隐喻场景。

**封面文字（碎片开场拼合后的画面）**
- 大字 = **概念词，2–5 字**：心理学词，或更有分量的哲学词（他者性、上手性、情绪成本），或大众熟词。
- 大字下方的字幕 = **口播第一句**（问句或判断句都可以）。

**发布标题**
- **用陈述句**（用户不喜欢问句标题）：第一句是判断句就直接用；第一句是问句，就用第 2 句的回答或全片结论句。
- 25 字以内；不写概念名（概念放封面和话题里）。每期给 3 个备选，标明推荐。

**简介**：没有单独的简介，直接复制 `发布标题 #话题1 #话题2 #话题3 #话题4 #话题5`。
话题顺序：`#哲学` `#心理学`（领域）→ `#概念名` → 1–2 个场景词 → 1 个泛流量词（`#抖音精选` `#深度思考` `#自我成长`）。

## 8. 交稿前自查（只问效果）

- [ ] 读了全部认可稿和 1–2 篇相近对标的原文，附了仿写对照表
- [ ] 开头能让人停下来，后面接得住
- [ ] 讲清楚了一个道理，并往下挖了一层
- [ ] 研究、人名、引文都真实可查
- [ ] 没有段子腔、网络梗、编造的亲历、口号；也没有为了凑而硬塞的固定句式
- [ ] 大声读一遍，语气平静自然
- [ ] 字数大致符合规格（可浮动）
- [ ] 3 个陈述句标题 + 话题；封面主体原创、处理借鉴对标，各附一句“它在说什么”
