# 参考拆解：正文段（拼贴段）呈现方式

来源：抖音 @江东陵《人其实需要的不是形式，而是关系的质量》，1280×720 横屏，约 3:21。
分析范围：第 7–37 秒（开场之后的正文段）。只学手法和节奏，不复制画面与文案。

## 1. 30 秒里的镜头结构

| 时间 | 场景类型 | 画面 | 台词作用 |
| --- | --- | --- | --- |
| 7–16.5s | 关键词云 | 纯米色纸纹底；5 个红色粗宋关键词随台词逐个弹出，散落排布、错落不齐；说完一齐淡出 | 罗列“好关系是什么样的” |
| 16.5–24.5s | 超现实拼贴 | 纸底上叠一条撕边的冰面照片带，上方一颗星球、右侧一根天线装置；台词转折时左侧淡入一个宇航员和倒地的人 | 用画面隐喻“身边有人却依然孤独” |
| 24.5–33s | 聊天界面模拟 | 微信样式对话：左侧白色气泡“问候”，右侧绿色气泡“敷衍回复”，带圆形头像；随后左上淡入一张撕边复古照片（同床而眠的夫妻） | 把抽象观点落到日常场景 |
| 33–37s+ | 概念公式 | 蓝色带引号的“形式” → 金色向下箭头 → 红色“关系的质量”，依次出现 | 给出结论，一句话收束 |

节奏：每 2–3 秒画面就有一次变化（新元素出现或场景切换），一个场景持续 4–10 秒。

## 2. 背景风格

- 全程同一张**米色/灰白纸纹底**（细腻纤维与斑驳），不换底色，靠上面的元素区分场景。
- 写实照片只以“拼贴片”的形式出现：撕边的照片带、抠出的人物与物件，不铺满全屏。
- 场景切换：旧元素整体淡出回到空白纸底，再开始堆叠新元素。没有花哨转场。

## 3. 叙述风格

1. 先**罗列**：用几个并列短语描述理想状态。
2. **价值判断**：把它定性为稀缺、可遇不可求。
3. **转折**：最深的问题不是 A，而是“有 A 却仍然 B”。
4. **日常例子**：用聊天、同床这类人人经历过的画面落地。
5. **公式化结论**：“不是 X，而是 Y”。
6. **推广**：把结论套到更多身份、关系上。

每条字幕一个短分句；画面跟着台词里的关键词走，台词说到哪个词，那个词或对应物件就出现。

## 4. 素材风格

- **复古照片抠图**：低饱和、带胶片颗粒的老照片质感（人物、物件、星球、机械装置），边缘干净或撕纸边。
- **超现实组合**：把不相干的元素拼在一起（星球 + 冰面 + 宇航员）形成隐喻，不追求写实。
- **界面模拟**：干净的聊天气泡、头像，像截图但是重新排版的。
- **文字即画面**：关键词、引号、箭头本身就是主视觉。

## 5. 展示方式与样式

- **元素出现**：约 0.3–0.5 秒淡入，基本不做位移/缩放动画；新元素叠加，旧元素保留，直到场景结束一起淡出。
- **配色**：纸底米白；关键词主色深红（约 #B01E23），对比概念用藏蓝（约 #2B3F7A），连接符号用金黄（约 #E8A317）；照片低饱和暖灰。
- **关键词字体**：粗宋/标宋，比字幕大一倍左右，散落在画面上半部和中部，避开底部字幕区。
- **字幕与水印**：与开场相同，底部黄色中文 + 白色英文，顶部居中半透明水印。

## 6. 对本项目的落地建议

正文段可以拆成 4 种可复用的“场景模板”，由配置里的台词时间轴驱动：

| 模板 | 输入 | 素材来源 |
| --- | --- | --- |
| 关键词云 `keywords` | 词列表 + 每个词的出现时间 + 颜色 | 纯排版 |
| 拼贴 `collage` | 底部照片带 + 若干抠图元素（位置、出现时间） | 生图工具：透明底 PNG |
| 聊天 `chat` | 对话列表（左/右、文字、出现时间） | 排版 + 生图头像 |
| 公式 `formula` | A → B（文字、颜色、出现时间） | 纯排版 |

字幕、水印继续走 `video/text.py`；纸纹底用生图工具生成一张无缝纸纹图后全片复用。
