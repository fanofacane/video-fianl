# 参考视频呈现风格共性（6 个视频）

样本：两个账号的 6 个横屏哲学 / 心理学视频，1280×720。其中 4 个长版（约 3–3.5 分钟），2 个短版（约 65 秒）。
两个账号用的是同一套模板，说明这是这一类内容的通用做法。文案写法见 [../script-style.md](../script-style.md)。
只总结手法与规律，不记录原作者的画面与文案。正文段细节见 [body-collage-style.md](body-collage-style.md)。

## 1. 整片结构（4 个视频完全一致）

| 段落 | 时长 | 画面 |
| --- | --- | --- |
| 碎片开场 | 4–6 秒 | 黑底 → 玻璃碎片拼合成一张**写实氛围照片**（海边、雾中、雪地、荒漠水面），白色毛笔大字写本期**概念词**（2–4 字） |
| 过渡 | 约 0.5 秒 | 照片整体提亮、溶解成米色纸纹底 |
| 概念复现 | 3–8 秒 | 纸底上用红色大字再写一次概念词，常立刻变成公式：`概念 = 常见误解`（误解用蓝色） |
| 正文 | 约 3 分钟 | 米色纸纹底上的拼贴场景，一句台词一个画面变化 |
| 收尾 | 10–20 秒 | 回扣开场的比喻或金句；最后一个画面通常是一张色彩更亮的照片拼贴，情绪上扬 |

## 2. 背景

- 正文全程同一张**米色纸纹底**，从不换底色。
- 写实照片有三种用法：
  - **底部照片带**：占画面下半，上沿是撕纸边或照片原轮廓（山、海、桥、冰面、星球表面），人物站在带上。
  - **全屏照片**：少量情绪高点时使用（公路、荒野），停留 2–4 秒后回到纸底。
  - **局部撕边照片**：小块照片贴在角落，作为补充画面。

## 3. 素材（反复出现的“演员”）

- **复古人物抠图**是主角：上世纪中期的儿童、少年、绅士、夫妇，低饱和、带印刷颗粒。同一批人物在不同视频里反复出现，形成固定“演员阵容”：
  - 双手交叉的红发小女孩、托腮的格子衫男孩、拿帽子走路的男人、蹲着发愁的少年、背影剪影女人。
- **物件抠图**：钞票捆、怀表、老式电话、敞篷老爷车、热狗、冲浪板、自由女神像。用来把抽象词具象化（金钱、时间、欲望、目标）。
- **权威人物**：讲到某位思想家时，出现他的黑白肖像抠图。
- **雕像**：古典石膏雕像，表示“人性 / 心理”这类抽象主题。
- **界面元素**：手机截图（刷短视频）、聊天气泡。
- 素材互相不需要比例一致，故意拼贴感、超现实。

## 4. 文字即画面（除字幕外的屏幕文字）

| 形式 | 样式 | 用途 |
| --- | --- | --- |
| 概念词 | 黑色粗宋 + 中文引号 “”，居中偏上 | 引出一个术语 |
| 概念定义 | 概念词下方一行红色小字（带括号） | 给术语下定义 |
| 公式 | `A = B`、`A → B`、`A ← B`，A 红 B 蓝，符号黑或金 | 澄清误解、对比、因果 |
| 关键词云 | 3–5 个彩色大字错落排布，逐个出现 | 罗列 |
| 对话气泡 | 绿底黑字矩形框，贴在人物旁边 | 模拟人物说的话 / 内心独白 |
| 引语 | 大段红字，逐字淡入 | 结尾金句 |

颜色：深红（约 #B01E23）、藏蓝（约 #2B3F7A）、金黄（约 #E8A317），加黑色。

## 5. 动态与节奏

- 元素出现：0.3–0.5 秒淡入，几乎没有位移、缩放、旋转。
- 元素累积：同一场景里新元素不断叠加，旧的保留；场景结束时整体淡出回到空白纸底。
- 节奏：每 2–4 秒有一个新元素或新文字；一个场景 5–15 秒。
- 字幕：每条一个短分句，底部黄色粗宋中文 + 白色英文；顶部居中半透明水印。全片统一。

## 6. 叙述与画面的配合

- 台词说到具体名词（钱、时间、手机、父母）→ 出现对应物件或人物抠图。
- 台词提出术语 → 概念词 + 定义。
- 台词纠正误解或做对比 → 公式。
- 台词举日常例子 → 人物抠图 + 对话气泡 / 聊天界面。
- 台词进入情绪高点 → 全屏照片或底部风景照片带。

## 7. 短版（约 65 秒）的差异

- 开场同样是碎片拼合 + 白色概念大字，但只有 2–3 秒，紧接着就进入第一个拼贴场景。
- 节奏更快：每 2 秒左右就有画面变化，场景 3–8 秒。
- 更多用**多人物对话**表现场景：2–3 个复古 / 古典人物抠图并排，各自头顶一个对话气泡。
  - 气泡两种：绿底方框（像聊天消息），白底黑边圆角带尾巴（像漫画）。气泡可以略微倾斜。
- 真实生活照片（聚餐、会议）也会被当作背景片，人物脸部用花朵等物件遮挡，增加超现实感。
- 金句用黑色粗宋整句逐行打出，放在画面上半部。
- 结尾是一张开阔的风景照（荒漠、草地），人物背影走远，配最后一句金句。

## 8. 对本项目的实现清单

全片固定为：**碎片开场（已完成）→ 概念复现 → 正文场景序列 → 收尾**。正文需要的场景模板：

| 模板 | 说明 |
| --- | --- |
| `concept` | 概念词 + 引号 + 红色定义小字 |
| `formula` | `A = B` / `A → B`，逐段出现 |
| `keywords` | 3–5 个关键词错落出现 |
| `collage` | 底部照片带（可选）+ 若干抠图元素，按时间点淡入 |
| `bubble` | 人物旁的绿底对话气泡 |
| `chat` | 微信样式聊天界面 |
| `photo` | 全屏照片 |
| `quote` | 结尾红字金句逐字出现 |

素材：每期按台词临时用生图工具生成透明底人物 / 物件，不维护固定素材库。
