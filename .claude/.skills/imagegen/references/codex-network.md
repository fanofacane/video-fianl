# Imagegen 连接排查

项目副本说明，2026-10-25。CLI 读取项目 .env 的 OPENAI_API_KEY 和 OPENAI_BASE_URL，进程环境变量优先。不要打印密钥、完整认证头或 env 文件。当前用户指定的是第三方兼容服务，官方参数与该服务的实际支持可能不同。

1. dry-run 成功只证明本地请求构造通过，不代表服务连通或账号可用。
2. 检查实际执行环境是否安装 requirements.txt；检查 URL 是否包含 /v1 且没有中文标点。
3. 鉴权、额度、模型不存在或参数不支持时报告真实错误；不要静默切换到官方端点或其他模型。
4. 超时后先说明结果未知，避免自动重发付费请求。SDK 自动重试关闭，批量 max-attempts 默认 1。
5. 如宿主有网络、工具或审批限制，遵守当前宿主规则；本文件不授予额外权限，也不要求在没有限制时反复确认。
